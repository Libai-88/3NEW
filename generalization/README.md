## 方案要点（均有实验支持）

1. **跨体系通用描述符体系**：以「原料描述符（角色/树脂类型/固含/EEW/官能团密度等）+ SMILES 分子描述符 + 显式比例」替代原料编码，使多体系配方可表达进同一特征空间（实验 D：跨体系编码 PCA 验证）。**口径说明**：专有原料描述符以供应商 TDS/SDS 实测为主（77/80 种，用量加权 99.6%，见「实验 U」），基线为「化学类别典型值」估算、非实测；**聚酯金黄已从原始配方/性能表补全 26 条实测标签**（含 T弯/MEK/水煮），环氧-配比方案仍无实测标签，跨体系预测迁移仍为开放缺口（见「数据局限」）。
2. **四阶段标签补充流水线**：迁移冷启动 → 质量门控伪标签 → 主动学习实测 → 迭代。质量门控（源域 CV R²≥0.2）防止伪标签在难预测目标上造成损害。
3. **诚实评估协议（实验 T 加固）**：按样本 ID 去重（重复测量取均值）、**折叠内 top-N 特征选择**（选择步骤不接触验证折标签）、折叠内 OOF 系列编码、公共噪声掩码（|OOF 残差|≤2×重复测量噪声 std，跨臂同一评估集）、分类阈值不在报告数据上寻优（固定 0.5）、多体系留出验证、缺失工艺按 NaN。
4. **终极版模板 v3**：以「体系配置」表驱动，新增体系/目标属性无需改结构；数据验证下拉 + 未登记原料自动标红，杜绝手输错别字。
5. **配方级机理特征层**：在线性加权描述符之上新增 40 维非线性机理量（当量浓度、化学计量比、Flory 交联密度、Fox Tg、Arrhenius 固化度、Hansen 距离、PVC），并对方向证据充分的列施加 XGBoost 单调先验作正则化（实验 P\~T）。
6. **预测侧防线**：新配方预测输出携带「系列编码 / 全局均值(新系列)」来源标记与适用域越界特征清单（`domain_check`），批量预测导出附越界列；新系列的诚实使用方式是 1\~2 个试点实测回入后再依赖数值。

### 最终验证（当前诚实协议：折叠内选择 + 公共掩码，实验 T）

评估协议在实验 T 中完成加固（详见 `generalization-hardening-report.html`）：top-N 特征选择在每折训练标签内完成、噪声掩码由折叠内 OOF 残差构造、水煮阈值不再在报告数据上寻优、缺失工艺的机理固化量按 NaN 处理。20 种子终验：

| 目标          | 配置                                                                             | 结果                                                         | 达标                   |
| ----------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------- | -------------------- |
| T弯（回归）      | sqrt + 折叠内选择 + 公共掩码(n=261) + keep=96 k=8 w=0.85 + 机理单调先验                       | 掩码内 R²=**0.792±0.002**；全样本 R²=0.717（工作台自掩码端到端 0.807/0.735） | ✅ >0.7（已贴噪声地板 0.789） |
| MEK 擦拭（两阶段） | AFT 边界判别（acc=0.925 / 截尾召回=0.65 / AUC=0.942）+ 未截尾回归（p\_hi 特征、机理列 NaN 口径）keep=45 | 未截尾 R²=**0.507±0.006**（n=292）                              | 诚实口径                 |
| 水煮等级（分类）    | 折叠内选择 keep=80 + **固定阈值 0.5**                                                   | acc=**0.772**（机理臂，AUC=**0.832**；base 臂 0.756/0.809）        | 判别力以 AUC 为准          |

> 水煮未再报 0.8：旧口径的 0.804/0.805 含「在同一份 OOF 上调阈值再汇报」的约 +0.035 偏置，公平口径下调阈值不优于固定 0.5。0.8 的达成依赖补测降噪，不靠口径达成。
>
> MEK 口径说明：实测样本中 43 个记录值恰为 300（真实值 ≥300 未知，视为右截尾），3 个 >300（350/400/550）为真实观测值。「未截尾 R² + 边界 acc/AUC」双指标由实验 K/L（`scripts/mvp76_experiments.py`\~`mvp77c_experiments.py`）确立，截尾判别统一为「仅恰为 300 视为右截尾」。

### TDS/SDS 实测层与数据集复跑（实验 U）

供应商技术档案（`TDS-SDS/`，291 份 TDS+SDS）到位后，新增最高优先级的描述符实测层 `workbench/tds_sds.py`：不再用「化学类别典型值」一填到底，而是**逐字段引用档案原文**并把等价口径统一到货状态（EEW/OHV/AV 与官能团密度绑定为标准换算，消除旧库两列相差 2\~3 倍的互矛盾）。对档案未直接给出的量（如数均分子量、羟值），用档案的组成/CAS/分子式**缩小范围后推算**，而非通用典型值。`merged_data.pkl` 的加工链因此升级为：类别典型值 → 送检组成(compo\_rules) → 占位修正(handbook\_fixes) → **TDS/SDS 实测(tds\_sds)**。

**内部代码 ↔ 档案牌号的匹配**：数据集的原料代码是厂内代号，与档案牌号可能不一致，靠三类信号对号入座而非猜——① 送检组成名称，如 `RJ173M`=「聚酯树脂 50173-M-40」→ 长兴 ETERKYD 50173-M-40、`RJ561`=「50561」→ 50561-R-60、`RF401`=PR401 → 湛新 PHENODUR PR 401/72B、`RY460`=「ITBL-460S」→ 万华 WANNATE ITBL-460S；② 代码名自证，如 `RH601`（SM601RX75）→ 三木 SM601R-75、`1510蜡25%` → 路博润 Lanco 1510 EF、`10%135`=ACA-EAA1 的 10% 稀释；③ **数字连续性**：厂内数字与档案牌号数字连续对上即视为同一种（如 `IR190/IR191`=9 型环氧 ≈ 国都 YD-019、`AZ551`=毕克 BYK-3550）。凡未获档案覆盖的才进入族推断层。

**族推断层（`workbench/tds_sds.py::FAMILY`）**：档案内「牌号未识别」的原料（集中在聚酯金黄主用环氧 IR909/IR557/IR868 等、环氧-配比方案的 IR877、丙烯酸 IA151/聚酯 RJ183 等），**不**套通用典型值，而是按**同化学族在档案中的实测值**近似——如 IA151 取丙烯酸多元醇族（常州科邦 SU-4660：羟值 70/酸值<6/比重 1.03；恒裕辰 HYC-R926；湛新 SETALUX1187；彤德 RB819）的到货中值；IR877 取双酚 A 环氧族（HY-2801/YD-019/HY-5100）量级。每条带 `依据`（引用来源）+来源标 `TDS族推`，一旦按物料编码确认牌号即可升级为直接实测。

**口径修正与化学计量诊断**：修复旧 `mech_desc` 的羟基当量换算错误（OHV mg KOH/g → mol/g 应除 56100，原来误除数小 100 倍），使 `r_phenol_epoxy` 等计量比量可解释。修正后四个臂均得出：环氧酚醛实际配方为**环氧过量**（`r_phenol_epoxy` 中位 0.14、P10–P90 0.11–0.21，几乎无一靠近化学计量 1），且该比值与 T弯 呈负相关（Spearman −0.24）——酚醛交联密度越高、T弯 越低，方向符合物理直觉，说明档案层数据下计量比已成为可用机理论据。

### MEK 截尾处理（`scripts/mvp76_experiments.py`、`scripts/mvp76b_experiments.py`、`scripts/mvp77_experiments.py`，实验 K/L）

| ------------------------ | ------------- | ------------- | ----------------------------------------------------------- |
| 代理目标（旧口径）                | 0.427         | 0.899         | 全样本 R²=0.708 为含截尾代理值的虚高口径                                   |
| 未截尾回归（丢弃截尾）              | 0.474         | —             | 仅在未截尾样本上训练与评估                                               |

## 数据局限（已知口径）

以下为合并版数据集与应用边界的诚实说明，模型结论应在此范围内解读：

1. **专有原料描述符：77/80 种已由 TDS/SDS 实测或同族推断锚定，类别典型值的用量加权占比为 0.0%**：`workbench/materials.py` 的树脂/助剂基线原本是「化学类别典型值」估算，且存在同族同值退化（多种环氧共享同一组典型值）。新增 `workbench/tds_sds.py` 最高优先级实测层（`TDS-SDS/` 291 份档案）后，逐字段把描述符改为档案原文，并按到货状态统一 EEW/OHV/AV 与官能团密度口径（消除旧库两列相差 2\~3 倍的互矛盾）。对档案内**牌号未识别**的原料，按**同化学族档案实测值**近似（族推断层，见「实验 U」），而非套通用典型值；仅剩 `DMP`、`209-基料` 两项（合计 0.3% 质量权重）因代码歧义留待物料编码确认。真实分子描述符来自 `smi_desc.py`（覆盖 41 种原料）。
2. **占位行的可判部分已修正，剩余需 SDS 核定**：原 15 行「专有估算」占位记录曾把同一套默认值复制到化学完全不同的原料上（MIBK/DBE/DPM 与丁酮共用"密度 1.0、分子量 110、沸点 160"），且部分固含与自身代码名矛盾。现已按 `handbook_fixes.py` 处理：5 行同物合并（MEK→丁酮、50173M→RJ173M 等）、8 行改为公开手册值或名称自证值、2 行（DMP、209-基料）标注「待确认」。这些原料集中在无标签的环氧-配比方案体系，因此修正不改变当前三项目标指标，作用是使那 112 条配方可用于跨体系外推与补测排程。
3. **小样本体系不可并入池化评估**：聚酯金黄的 27 条水煮实测集中在 2 级（该体系在观测中几乎无水煮失败），对水煮的判别信息有限；其 T弯 11 条、MEK 17 条。池化训练下该体系 MEK 的体系内 R² 为 −30.0（等权）至 −4.3（×3 加权）。环氧-配比方案的 66 条 T弯 由 T弯G 腐蚀判定折算（另一测试口径）。所有指标必须按体系拆分报告，综合值只作参考。
4. **标签覆盖仍聚焦 1 个主力体系**：486 样本中「环氧酚醛」实测标签最全（T弯 277 / MEK 318 / 水煮 189）；「聚酯金黄」已按原表补全（T弯 11 / MEK 17 / 水煮 27）；「环氧-配比方案(112)」已从 T弯G 折算补 66 条 T弯（无 MEK/水煮，46 条因值为 `点状/2级` 等无法量化仍无标签）。有标签 / 无标签样本在 `w_EEW`（有标签均值 1773 vs 无标签均值 470）、`w_Tg`、`xlink_frac` 上系统性偏移，属真实化学域差异而非录入错误。跨体系泛化与 LOSO 仍因此无法在当前数据上完整验证。
5. **全新系列的数值外推不保证可用（实验 T：LSO 实测）**：留一系列外推（n≥12 的 13 个系列）样本量加权 R²≈−0.05，化学距离近的系列可达 0.5\~0.86、错开的系列失败至 −5.2，任何特征臂无系统性差异。这不是建模缺陷而是数据边界：系列间存在配方批次级偏置，无标签信息时不可辨识。**使用规则：新系列先测 1\~2 个配方回入（系列编码生效）再依赖预测数值**；工作台对未登记系列标注「全局均值(新系列)」并对适用域越界发出警告。
6. **MEK 截尾口径**：按域建议约 100 次即可满足买家需求，300 为退让上限；仅记录值恰为 300 视为右截尾，>300（如 350/400/550）为真实观测值。数据字典与本 README 已统一该口径。
7. **水煮等级口径**：等级 1（最好）~~4（最差），员工偶记 5~~10 级均属不合格，统一归并为 4。二值化阈值 ≥4 为现行口径；分类决策阈值固定 0.5（公平口径下调每系列阈值不优于固定值，实验 T）；序回归替代方案（实验 Q）未采纳。
8. **烘烤条件覆盖有限**：仅环氧酚醛（345 条中的 345 条有效记录）含烘烤温度/时间，且只分布在 200℃/10min 与 205℃/17min 两个组合；聚酯金黄与配比方案无烘烤记录（聚酯金黄源文件中仅 25.11.11 一批在设计说明里记有"按205\*12min"，不足以覆盖该体系）。Arrhenius 等效固化时间等工艺机理量因此只在主力体系上有意义——对无记录样本这些机理列为 **NaN（不可知）**，不是 0；两个烘烤组合也意味着固化机理量在本数据内几乎无对比度，其价值要等工艺跨度数据到位才能兑现。
9. **无标签体系标签补齐依赖补测**：伪标签 / 推荐测试为半监督 / 主动学习流程（实验 E/S/A）的回填候选状态，当前数据未出现；补齐实测标签后跨体系泛化才能验证。
