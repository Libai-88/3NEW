  • 量化了三处系统性乐观来源：全局特征选择泄漏 +0.0094；水煮"折外寻优阈值"虚高约 +0.035，且公平口径下调阈值并不优于固定 0.5；机理特征在旧协议下的 T弯增益部分来自候选池扩大放大的选择泄漏——在诚实协议下 T弯与基线统计持平（keep≥84），而 MEK（+0.010）与水煮（AUC +0.022）的收益是真的。
  • 新系列外推（LSO）是数据的真实边界：任何特征臂都无法在无试点实测时可靠预测一个从未见过的系列（R² 均值 −0.05~−0.13，最差系列 −5.2）。对策是流程而非模型：新系列先测 1~2 个配方、经系列编码回入，模型即回到域内水平。工作台预测路径已内置该语义（"全局均值(新系列)"标记 + 适用域越界警告）。

1. 加固原则

本轮所有措施按同一准入标准检验：让评估更严时数字应当下降或持平；让外推压力更大时方法不应当失效。据此采纳或拒绝每项改动——

  • 采纳 折叠内特征选择（消除选择泄漏）、公共噪声掩码（跨臂可比）、缺失工艺 NaN 化（消除伪域）、T弯机理列单调先验（物理正则）、水煮固定 0.5 阈值（公平口径下最优）、选择预算复核后 keep=96。
  • 拒绝 序回归（工程化输出受限且无公平增益）、体系样本加权、工艺缺失指示列（均无增益）、每系列调阈值（公平口径劣于不调）、任何"新系列自由外推"的能力宣称。

2. 协议审计：三处乐观来源与修复

2.3 缺失工艺记 0 → NaN

无烘烤记录样本（141 行，聚酯金黄与配比方案为主）的固化类机理量（t_eff_min / ne_effective / cure_drive / cure_margin / cure_margin_eff / cure_margin_neg）此前记 0，与"真实低固化"混成同一伪域。改为 NaN 后由树模型学习缺失分裂方向。这一改动直接翻转了 MEK 结论（§4.2）：旧协议"机理列损害 MEK（−0.030）"正是伪域所致。

2.4 同批修复的特征卫生问题

  • sqrt 逆变换统一加下截断（clip(p,0)²），消除负预测平方回正的假象。
  • 合并版数据集「配方级机理特征」表中固化类列对缺记录样本输出为空单元格，与建模口径一致。

4.2 MEK 结论翻转的归因

旧协议（mvp85，全局选择 + 固化列记 0）给出"机理列 −0.030"；修复两处缺陷后（折叠内选择 + NaN 口径）为 +0.010。伪域惩罚被解除：无烘烤样本不再被强制映射到"零固化"区域与真实固化梯度冲突。

4.3 单调先验（物理正则）

对方向证据充分的 7 个机理列施加 XGBoost monotone_constraints（mech_desc.MECH_MONO_SIGN_TBIAN）：交联密度/交联剂比/Fox Tg/PVC 升 → T弯 mm 升（更脆）；当量偏离/玻璃化受限 → mm 降（欠固化更柔）。不确定的列一律不约束。效果：域内 +0.0012（p=0.0005，跨 20 种子稳定），LSO 中性。收益小但方向符合机理预期、且属于正则化（降低方差而非增加容量），采纳为 T弯默认。

7. 使用指引（防止误用外推能力）

  • 新系列必须试点：预测全新系列时模型输出带「全局均值(新系列)」标记，该路径的诚实精度即 LSO 数字（不保证优于训练均值）。标准流程：新系列先测 1~2 个配方 → 录入 → 该系列进入系列编码 → 后续配方按域内精度使用。
  • 看越界警告：预测结果出现「⚠外推:n/N 特征越界」时，配方在化学空间上超出训练包络，输出仅供排序参考。
  • MEK 截尾口径不变：≥300 判定由 AFT 边界给出（acc 0.93 / AUC 0.94），未截尾 R² 只在 <300 样本上评估。
  • 水煮按体系拆分读：聚酯金黄 26 条实测全为 2 级（无失效样本），其 acc=1.0 是常数正确，不提供判别证据。
  • 指标不追高：T弯域内已贴噪声地板 0.79；提升路径只剩测量降噪（重复 4 次取均值可将上限提至 0.95）与 TDS 到位后的描述符替换。
