# 数据困境解决方案 · 实验验证

本目录是「3NEW 三新项目研发」第二阶段（`../generalization/`）的**数据困境专项实验**：针对「R²>0.9 目标受数据质量制约」的问题，通过公开数据检索、噪声地板分析与多路径对照实验，给出突破性能上限的最优方案。

## 核心结论

数据困境的根因是**测量噪声**，而非数据量或外部数据可得性。当前 T弯 模型 R²=0.791 已逼近由测量噪声（系列内 std=1.244）决定的理论上限 0.791，继续增加样本量、合并外部数据或更换模型均无法突破该上限。

| 路径 | 实验结论 | R² 变化 | 优先级 |
| --- | --- | --- | --- |
| 外部公开数据集整合 | OOD 距离 1887×，目标尺度不兼容，强制合并反而有害 | -0.009 | 放弃 |
| 半监督伪标签回放（209 个无标签配方） | 同设置下 R² 0.684 → 0.838，作为正则化手段有效 | +0.153 | 采用 |
| 主动学习（新增 30 个最优标注） | 各选择策略收益相近，样本量非瓶颈 | +0.008 | 辅助 |
| 重复测量降噪（4 次取均值） | 有效噪声 1.244 → 0.622，R² 上限 0.791 → 0.948 | +0.157 | 核心 |

**最优方案**：以「降噪为核心、伪标签为补充、主动学习为辅助」的三层策略。对现有样本补做 3~4 次 T弯 重复测量取均值即可突破 R²>0.9，无需新增配方实验。

## 实验要点

1. **实验 E（外部数据）**：从 MDPI 卷钢涂料论文提取外部树脂/涂层数据，映射进当前特征空间后计算 OOD 距离（1887×），并做强制合并对照实验，证明外部数据与当前任务在原料体系、测试协议、目标尺度上三重不兼容。
2. **实验 S（半监督）**：对 209 个无标签配方中 180 个分布内样本，用 5 折 OOF 模型生成伪标签，以权重 w=0.5 回放进训练集，同设置下 R² +0.153。
3. **实验 A（主动学习）**：模拟有限标注预算（30 个），对比随机/不确定性/多样性/混合策略，各策略收益相近且边际小，印证瓶颈不在样本量。
