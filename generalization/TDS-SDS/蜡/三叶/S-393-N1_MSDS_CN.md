## 第三部分：危害说明

**危害预见性**：有轻微气味的白色光滑粉末。高浓度的粉尘会引发粉尘爆炸。在这种情况下，远离热、火花、明火。所有设备接地。溢出会滑。

**健康影响**

| 接触途径 | 影响 |
|---|---|
| 眼 | 可能轻微刺激 |
| 皮肤 | 重复或长期接触可能引起皮肤过敏 |
| 摄入 | 在正常的工业使用中没有危害 |
| 吸入 | 可能刺激鼻子、喉咙、呼吸道 |
| 长期影响 | 未知 |
| 致癌物 | NTP：没有列出；IARC：没有列出；OSHA：没有列出 |
| 恶化条件 | 未知 |

## 第四部分：急救措施

| 接触途径 | 急救措施 |
|---|---|
| 眼 | 用水冲洗眼睛至少 15 分钟。如果刺激持续则找医生。 |
| 皮肤 | 用肥皂和水洗净。如果刺激持续或加重则找医生。熔化材料的烧伤是热烧伤。热材料往往会粘在肉体上，尤其在固化后。尽可能快地冷却。寻求医生帮助。 |
| 消化道 | 不会导致呕吐。如果发生呕吐，要低头防止吸入。严重时寻求医生帮助。 |
| 吸入 | 如果接触于高浓度的粉尘和烟中，则需要新鲜的空气。呼吸困难，则输氧并找医生。 |
| 健康影响途径 | 吸入、肠道。 |

## 第六部分：事故处理

小心处理，溢出物滑。移走燃烧源。清除避免灰尘。若材料熔化，等其冷却固化后再清理。勿将清理废物倒下水道中。

## 第七部分：生产和贮藏

- 正常储存条件。"储存条件"是指凉爽（7 ℃ – 32 ℃ [45 °F – 90 °F]）、干燥、湿度通风适宜的区域。
- 避免过高温度或严寒，避免高湿度，避免污染产品。
- 使用产品时小心周围环境中有热、火花、静电、明火。
- 保持良好工业卫生习惯。将吸入熏烟和灰尘减少到最低。

## 第八部分：个人防护

| 防护类别 | 要求 |
|---|---|
| 呼吸防护 | 空气中的浓度超出暴露极限则需要 NIOSH/MSHA 允许的防尘面罩或呼吸器。 |
| 眼防护 | ANSI（Z87.1）允许的带侧面防护的安全镜或护目镜。在熔化材料上工作时，需戴安全镜和脸部防护。 |
| 皮肤防护 | 戴长袖子的密封手套把皮肤接触减少到最低。 |
| 工程防护 | 提供当地的排气通风装置以确保空气的浓度在暴露水平之下。 |
