# ETERKYD 50170-M-52 高分子量聚酯 — 技术数据表 (TDS)

**供应商：** 长兴材料工业股份有限公司 / Eternal Materials Co., Ltd.
**产品类型：** 溶剂型高分子聚酯

---

## 1. 产品简介

ETERKYD 50170-M-52 为溶剂型高分子聚酯，可与酚醛树脂、氨基树脂、封闭型多异氰酸酯等搭配，作为具有杀菌功能的烘烤型罐头金属涂料，其抗化性及柔韧性佳。除作为涂料使用，亦可用于接着，对多样基材具有良好的密着性及粘结强度。

## 2. 产品特性

- 耐化性佳
- 高加工性
- 对金属密着佳
- 具良好杀菌功能 (sterilization-resistant)
- 符合 FDA 及 GB 食品法规

## 3. 建议用途

- 卷材涂料及接着
- 耐深冲和消毒试验的罐头涂料
- 网印油墨
- PET膜、铝箔、铜箔、纺织品、彩色钢板的层压粘合剂
- 纺织物印刷

## 4. 产品规格

| 项目 | 规格 |
|------|------|
| 外状（目视） | 澄清至微雾 |
| 酸价 (mg KOH/g, solid) | 4-6 |
| 玻璃转化点 (Tg, °C) | 52 |
| 色数 (Gardner, 40%) | < 2 |
| 粘度 | Z1-Z2 |
| 溶剂 | S150 / PMA / BCS |

## 5. 储存条件

保持密封，存放于室内阴凉干燥处，维持通风良好，避免阳光照射，远离火源。

**保存期限：** 12个月

## 6. 溶解性

可稀释于以下溶剂：
- Solvent Naphtha 100
- Solvent Naphtha 150
- 单甲基醚丙二醇醋酸酯 (PMA)
- DBE
- 环己酮 (ANO)
