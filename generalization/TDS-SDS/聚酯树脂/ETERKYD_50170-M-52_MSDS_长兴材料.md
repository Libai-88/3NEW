## 第2部分：危险性概述

**危险性类别：** 易燃液体类别3、急性经皮肤毒性类别5、皮肤腐蚀/刺激类别2、严重眼损伤/眼刺激类别2A、特定的靶器官毒性-单次曝光类别3（呼吸道刺激和麻醉剂）、危害水生环境-长期危险类别3

**信号词：** 警告

**危险性说明：**

| 代码 | 说明 |
|------|------|
| H226 | 易燃液体和蒸气 |
| H313 | 皮肤接触可能有害 |
| H315 | 造成皮肤刺激 |
| H319 | 造成严重眼刺激 |
| H335 | 可能造成呼吸道刺激 |
| H336 | 可能造成昏昏欲睡或眩晕 |
| H412 | 对水生生物有害并具有长期持续影响 |

**防范说明关键措施：**
- 远离热源、火花、明火，禁止吸烟
- 保持容器密闭，使用防爆设备
- 避免吸入蒸气/喷雾
- 戴防护手套、防护眼罩和防护面具
- 存放在通风良好处，保持低温，存放处须加锁

## 第4部分：急救措施

| 接触途径 | 急救措施 |
|---------|---------|
| **眼睛接触** | 立即用流动清水冲洗，确保彻底清洗，如疼痛持续立即就医 |
| **皮肤接触** | 立即脱去所有被污染的衣物，用流动清水和肥皂冲洗皮肤，如有刺激就医 |
| **吸入** | 将患者转移出污染区，如呼吸停止进行人工呼吸，必要时心肺复苏，立即就医 |
| **食入** | 禁止催吐。让病人前倾或左侧卧保持呼吸道通畅。用水漱口，慢慢饮用大量液体。立即就医。 |

## 第5部分：消防措施

**灭火剂：** 泡沫、化学干粉、BCF（当法规允许时）、二氧化碳、喷水或水雾（仅适用于大火）

**火灾/爆炸危害：**
- 液体和蒸气易燃，蒸气与空气能形成爆炸性混合物
- 蒸气可能会飘散到离火源相当远的地方
- 燃烧时可能释放有毒的一氧化碳(CO)烟雾

---

## 第6部分：泄漏应急处理

**小量泄漏：** 清除所有点火源，用蛭石或其他吸附性物质收集吸附，收集于易燃废弃物容器中。

**大量泄漏：** 疏散人员，报告消防队，防止泄漏物进入下水道或水体，用沙子、土或蛭石吸收，使用不产生火花的工具。

---

## 第7部分：操作处置与储存

**操作处置：**
- 禁止在容器附近切割、钻孔、焊接
- 所有设备应连接和接地，防止静电放电
- 禁止用塑料桶
- 在通风良好的区域使用，禁止吸烟、明火或点火源

**储存：**
- 存放在经批准的防爆区域，阴凉、干燥、通风良好
- 远离不相容材料（强氧化剂）
- 存储区域配备灭火能力和可燃气体探测器

## 第8部分：接触控制和个体防护

**工程控制：** 使用防爆型通风设备，局部通风系统。
