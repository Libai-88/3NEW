## 2. 危险性概述

### GHS 分类

| 危险类别 | 级别 |
|----------|:----:|
| 急性毒性（口服） | 第4类 |
| 皮肤腐蚀/刺激 | 第3类 |
| 眼损伤/眼刺激 | 第2B类 |

- **警示名称**：警告
- **危险字句**：吞食有害；引起轻度皮肤刺激；引起眼睛刺激。

### 警戒与防范说明

**预防措施**：
- 避免吸入粉尘/烟/气体/烟雾/蒸汽/喷雾。
- 佩戴防护手套、防护眼镜、防护服。
- 使用时不得饮食、饮水、抽烟。
- 工作结束彻底冲洗。

**事故响应**：
- 如进入眼睛，用水冲洗几分钟，如戴隐形眼镜并可方便取出，请取出继续冲洗，如眼睛仍觉不适，马上就医。
- 如皮肤沾染，用大量水和肥皂清洗，如仍有不适或过敏，请就医。
- 如误吞咽，请马上就医。
- 污染的衣服清洗彻底后方可重新使用。

**存储**：
- 保持容器密闭；存放于阴凉通风处；放在儿童伸手不及之处。

**处理**：
- 按照本地/地区/国家/国际规则处理内含物/容器。

## 4. 急救措施

| 接触途径 | 急救措施 |
|----------|----------|
| **吸入** | 将患者转移到空气新鲜处，休息，保持有利于呼吸体位。若不舒服，送医院或寻求医生帮助。 |
| **皮肤接触** | 脱去被污染衣物，马上用肥皂和大量水冲洗。若清洗后仍不适，请就医。被污染衣物清洗干净后方可重新使用。 |
| **眼睛接触** | 立即用流动清水冲洗眼睛至少15分钟。如戴隐形眼镜并可方便取出，则取出隐形眼镜，继续冲洗，并立即就医。 |
| **食入** | 立即漱口，如误服请即刻就医，只能在医生指导下进行催吐；请勿进行嘴对嘴人工呼吸。 |
| **对医生的特别提示** | 给受害者保暖；呼吸短促情况下可吸氧。症状可能会延后发生，根据症状处理。 |

## 5. 消防措施

- **合适灭火剂**：水、泡沫、二氧化碳、干燥化学粉
- **不合适灭火剂**：未知
- **特别危险性**：发生火灾时可能会产生对人体有害气体
- **灭火措施及防护**：发生火灾时佩戴自给式呼吸器。消防人员佩戴合适的呼吸器并穿防护服，遵照工作场所的防火指示。

---

## 6. 泄漏应急处理

- **作业人员注意事项**：避免吸入蒸汽或气体，避免接触皮肤和眼睛。根据液体流动和蒸汽扩散的影响区域划定警戒区，无关人员从侧风或上风向撤离至安全区。建议应急处理人员佩戴自给式呼吸器，穿防护服。
- **环境保护措施**：如果安全的话，防止进一步泄漏或溢出。防止进入下水道或土壤。
- **清理方法**：如无风险，尽量禁止物料流动。可使用惰性吸收材料覆盖和吸收泄漏物，尽可能将泄漏物收集于清洁容器中再进行处置。产品回收后，用水冲洗泄漏区。

## 7. 操作处置与储存

### 操作注意事项
- 操作人员必须经过专门培训，严格遵守操作程序。
- 在通风良好的情况下操作。
- 建议操作人员佩戴呼吸器，戴化学安全防护镜，穿戴防护服或防护手套。
- 防止吸入蒸汽和喷雾，同时避免接触皮肤和眼睛。
- 脱去受污染的衣服。沾染的衣服清洗干净后方可重新使用。

### 储存注意事项
- 储存于干燥、阴凉、通风的库房。
- 保持容器密闭。
