## 第2部分 危险性概述

**紧急情况概述**：无色透明液体，有机溶剂气味。高度易燃液体。高浓度蒸汽会增加火灾或爆炸的风险。可能造成麻醉作用。

**GHS危险性类别**：

| 危险类别 | 类别 |
|----------|------|
| 易燃液体 | 类别2 |
| 皮肤腐蚀/刺激 | 类别2 |
| 特异性靶器官系统毒性（一次接触） | 类别3（麻醉作用） |
| 生殖毒性 | 类别2 |
| 特异性靶器官系统毒性（反复接触） | 类别2（中枢神经系统） |
| 对水环境的危害（急性） | 类别2 |
| 对水环境的危害（慢性） | 类别3 |

**警示词**：危险

**危险性说明**：
- H225 高度易燃液体和蒸气
- H315 造成皮肤刺激
- H336 可能造成昏昏欲睡或眩晕
- H361 怀疑对生育能力或胎儿造成伤害
- H373 长期或反复接触可能损害器官（中枢神经系统）
- H401 对水生生物有毒
- H412 对水生生物有害并具有长期持续影响

## 第4部分 急救措施

| 接触途径 | 急救方法 |
|----------|----------|
| **吸入** | 转移到空气新鲜处，保持利于呼吸的体位。如呼吸停止，立即人工呼吸。立即就医。 |
| **皮肤接触** | 立即除去受污染的衣物，用大量水清洗，然后用肥皂和水清洗。 |
| **眼睛接触** | 在流水下冲洗至少15分钟，冲洗时张开眼帘。 |
| **食入** | 立即就医，禁止催吐。用水彻底漱口。 |

---

## 第5部分 消防措施

**灭火剂**：化学干粉、二氧化碳、泡沫、干燥砂。避免使用直流水。

**特别危险性**：高度易燃，燃烧产生有毒烟雾（一氧化碳、二氧化碳）。蒸气与空气可能形成爆炸性混合物。密闭容器受热可能爆炸。

**防护措施**：佩戴自给式空气呼吸器（SCBA）和全身防护装备。

---

## 第6部分 泄漏应急处理

- 避免吸入喷雾/蒸汽，避免接触皮肤和眼睛
- 隔离危险区域，移除所有点火源
- 小泄漏：用干沙、蛭石等吸附，用不产生火花的工具收集
- 大量泄漏：用土、沙围堵，用不产生火花的工具或泵收集
- 避免释放到环境中

---

## 第7部分 操作处置与储存

**操作**：在通风良好处操作，远离热源/火花/明火，使用防爆设备，穿戴防护装备，采取防静电措施。

**储存**：保持容器密封，存放在阴凉通风处，避免阳光直射，远离氧化剂、酸、碱。推荐保管温度40℃以下。
