## 第一部分：产品数据表（TDS / PDS）

### 1.1 产品描述

Sparkle Silver (SS) J5361 是一种**非浮型细粒径铝颜料浆**，具有以下特点：

- 非浮型
- 常规纯度
- 抛光玉米片型结构
- 相比SS3333AR遮盖力更好、色调更平滑、正面更明亮 [pdf_10]

### 1.2 产品应用

- 适用于需要高遮盖力和良好金属效果的一般工业应用
- 卷材涂料等 [pdf_10]

### 1.3 技术指标

| 项目 | 指标 |
|------|------|
| 筛分分析（325目），质量百分比 | ≤ 0.5（最大） |
| 不挥发分，质量百分比 | 64.0% |
| 平均粒径 | 15.8 μm |
| 水分含量，质量百分比 | ≤ 0.15%（最大） |

[pdf_10]

### 1.4 使用指南

1. **预浸泡**：按浆剂比1:1~3:1用溶剂预浸泡1~8小时。细粒径产品需要更长的浸泡时间。
2. **分散**：采用低剪切低速混合，达到平滑均一的混合物。
3. **注意**：高剪切分散技术会破坏或扭曲铝颜料片，影响最终的美学效果，应避免使用。 [pdf_10]

### 1.5 储存条件

- 保存在原装运输容器中，保持密封
- 存放于干燥室温低于溶剂闪点的环境中
- 避免任何使颗粒悬浮或漂浮在空气中形成粉尘云的条件
- 详情请查阅MSDS或美国铝协会TR-2手册 [pdf_10]

### 1.6 REACH合规声明

星铂联雅思达颜料（济南）有限公司质检部于**2023年11月24日**出具声明：SSJ5361产品所用原材料**不含REACH SVHC高关注物质**，在制造过程中也没有刻意添加该类物质。 [img_2]

### 2.6 泄漏应急处理

- **个人防护**：疏散周围区域，切断所有点火源，提供足够通风，穿戴适当个人防护装备
- **环境措施**：避免溢出物进入土壤、河流、下水道
- **清理方法**：使用防火花工具和防爆装置，用吸尘器或彻底清扫 [pdf_9]

### 2.7 操作处置与储存

**操作**：
- 禁止食入，避免接触眼睛、皮肤及衣物
- 仅在充足通风条件下使用
- 远离热源、火花、明火
- 使用不产生火花的工具

**储存**：
- 储存于原装容器中，防止直接光照
- 置于干燥、凉爽、通风良好的区域
- 远离禁忌物（酸、卤代烃、氧化物质、强碱） [pdf_9]
