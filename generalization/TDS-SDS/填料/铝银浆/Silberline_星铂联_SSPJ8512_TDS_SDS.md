## 第一部分：产品数据表（TDS / PDS）

### 1.1 产品描述

SSPJ 8512 是一种**非浮型中等粒径铝银浆**，采用**银元型技术**开发，具有以下特点：

- 非浮型
- 银元型
- 铝鳞片边缘圆滑
- 高光亮，颜色纯净，金属效果好 [pdf_7]

### 1.2 产品应用

- 优质汽车原厂漆和修补漆
- 家电涂料
- 适用于要求高金属光泽和高闪烁度的应用 [pdf_7]

### 1.3 技术指标

| 项目 | 指标 |
|------|------|
| 筛分分析（325目），质量百分比 | ≤ 0.5 |
| 固含量，质量百分比 | 70.0% |
| 平均粒径 | 21 μm |
| 水分含量，质量百分比 | ≤ 0.15% |

[pdf_7]

### 1.4 使用指南

1. **预浸泡**：使用1~3倍量的溶剂预先浸泡1~8小时。粒径小的产品需要更长的浸泡时间。
2. **分散**：采用低速低剪切力搅拌，取得无结块的均一混合物。
3. **注意**：高剪切力会破坏铝片形状，影响最终视觉效果，不推荐使用。 [pdf_7]

### 1.5 储存条件

- 保存在密封的原装容器内
- 存放于干燥且室温低于溶剂闪点的地点
- 避免颗粒弥漫到空气中形成粉尘云
- 详情请查阅MSDS或美国铝金属协会TR-2指南 [pdf_7]

### 2.2 危险性概述

**GHS分类**：易燃固体 类别1

**紧急情况概述**：固体（糊状体），银色，芳烃气味（轻微）。易燃固体。吞咽可能有害。造成眼刺激。可能造成呼吸道刺激。可能造成昏昏欲睡或眩晕。对水生生物有毒并具有长期持续影响。不易生物降解。

**信号词**：危险

**危险性说明**：
- 易燃固体
- 吞咽可能有害
- 造成眼刺激
- 可能造成呼吸道刺激
- 可能造成昏昏欲睡或眩晕
- 对水生生物有毒并具有长期持续影响

**防范说明**：
- **预防**：戴防护手套、防护眼镜/面罩；远离热源/火花/明火/热表面，禁止吸烟；只能在室外或通风良好处使用；避免吸入粉尘
- **事故响应**：收集溢出物；如吸入，转移到空气新鲜处；如进入眼睛，用水小心冲洗至少几分钟
- **储存**：不可暴露在超过50℃温度下；保持低温，防日光照射；存放在通风良好处，保持容器密闭
- **废弃**：按地方/区域/国家/国际规章处置 [pdf_8]

### 2.6 泄漏应急处理

- **个人防护**：疏散周围区域，切断所有点火源，提供足够通风，穿戴适当个人防护装备
- **环境措施**：避免溢出物进入土壤、河流、下水道
- **清理方法**：使用防火花工具和防爆装置，避免产生灰尘；溢出物质置于适当容器中处理 [pdf_8]

### 2.7 操作处置与储存

**操作**：
- 穿戴适当个人防护设备
- 禁止食入，避免接触眼睛、皮肤及衣物
- 仅在充足通风条件下使用
- 远离热源、火花、明火
- 只能使用不产生火花的工具

**储存**：
- 储存于原装容器中，防止直接光照
- 置于干燥、凉爽、通风良好的区域
- 远离禁忌物（酸类、氧化性物质、强碱、卤代烃、氧化剂）
- 与氧化剂分开 [pdf_8]

### 2.8 接触控制/个人防护

**工程控制**：仅在充足通风条件下使用；使用防爆通风设备。

**个人防护**：
- **眼睛/面部**：安全眼镜，有侧罩的安全防护眼镜或防化学品飞溅护目镜
- **手部**：抗化学腐蚀、不渗透的手套
- **身体**：防静电防护服
- **呼吸**：必要时使用带微粒过滤网的呼吸器具
- **卫生**：接触化学物质后彻底清洗手、前臂和脸 [pdf_8]
