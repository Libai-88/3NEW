## 2. 危险性概述

**紧急情况概述**：对症治疗。症状可能有延迟性。持续观察患者情况。易燃液体和蒸气。吞咽或皮肤接触可能有害。造成皮肤刺激。可能造成皮肤过敏反应。造成严重眼损伤。吸入可能导致过敏或哮喘病症状或呼吸困难。可能造成昏昏欲睡或眩晕。怀疑可造成遗传性缺陷。可能致癌。可能对生育能力或胎儿造成伤害。对器官造成损害。长期或重复接触会对器官造成损害。对水生生物有害并具有长期持续影响。

## 4. 急救措施

| 接触途径 | 急救措施 |
|---|---|
| 吸入 | 将人转移到空气新鲜处，保持呼吸舒适体位。若出现呼吸症状：呼叫解毒中心或医生 |
| 皮肤接触 | 用水清洗皮肤/淋浴。立即去除/脱掉所有沾染的衣服。如发生皮肤刺激或皮疹：求医/就诊 |
| 眼睛接触 | 用水小心冲洗几分钟。如戴隐形眼镜并可方便地取出，取出隐形眼镜。继续冲洗。立即呼叫医生 |
| 食入 | 漱口。如感觉不适，呼叫解毒中心或医生 |

- **对保护施救者的忠告**：配戴适当防护装备，如接触到或有疑虑：求医/就诊。
- **对医生的特别提示**：对症治疗。症状可能有延迟性。持续观察患者情况。

## 5. 消防措施

- **适用灭火剂**：雾状水、干粉、泡沫、二氧化碳。
- **不适用灭火剂**：禁止使用直流水灭火，否则会引起火势蔓延。
- **特别危险性**：易燃液体和蒸气；可能释放有毒烟雾。
- **消防人员防护**：不得在没有适当防护装备的情况下尝试采取行动；须使用独立呼吸防护装置、完整身体防护。由上风处灭火。

## 6. 泄漏应急处理

- **非应急人员**：禁止明火、火花，禁止吸烟。仅限有资质的人员在穿戴适当防护装备的情况下进行处理。不要吸入气体/烟雾/蒸气/喷雾。
- **应急人员**：不得在没有适当防护装备的情况下尝试采取行动。更多信息请参考第8部分。
- **收容方法**：如可能，在无危险的情况下阻止泄露；避免排入下水道或水道。
- **其他信息**：将固体状的物质或固体残留物于受许可的地点清除。

## 7. 操作处置与储存

- **安全搬运**：确保工作点通风良好；远离热源/火花/明火/热表面；禁止吸烟；容器和接收设备接地/等势联接；只能使用不产生火花的工具；采取防止静电放电的措施；使用防爆装置。
- **卫生措施**：将物质的数量限制在操作所需的最小用量，并限制暴露其中的工人人数；提供局部或全面通风设备；必须经常清洁危险区域的地板、墙面及其他表面；不要吸入气体/烟雾/蒸气/喷雾；严防进入眼中、接触皮肤或衣服；小心操作与打开容器；将工作服与平时穿着的衣服分开并分开清洗；沾染的衣服清洗后方可重新使用；使用本产品时不要进食、饮水或吸烟；接触本产品后务必洗手。
- **局部通风和全面通风**：在封闭系统中操作本产品或者安排适当的抽风或风扇装置。
- **储存条件**：存放在通风良好的地方。保持低温。保持容器密闭。存放处须加锁。保持干燥，**低于10℃**阴凉以保证质量。
- **技术措施**：容器和接收设备接地/等势联接。
- **包装/容器材料**：储存在良好密封的原有集装箱中。

## 11. 毒理学信息

**急性毒性**：经口——吞咽可能有害；经皮——皮肤接触可能有害；吸入——无资料。

**组分毒性数据**：

| 组分 | 项目 | 数值 |
|---|---|---|
| 二甲苯（1330-20-7） | LD50 经口 大鼠 | 3500 mg/kg |
| 二甲苯 | LD50 经皮 兔子 | >4350 mg/kg |
| 二甲苯 | LC50 吸入 大鼠 | 29.08 mg/l/4小时 |
| 二甲苯 | LC50 吸入 大鼠（蒸气） | 27.57 mg/l/4小时 |
| 丁醇（71-36-3） | LD50 经口 大鼠 | 700 mg/kg |
| 丁醇 | LD50 经皮 兔子 | 3402 mg/kg |
| 丁醇 | LC50 吸入 大鼠 | >8000 ppm/4h |

- 皮肤腐蚀/刺激：造成皮肤刺激。
- 严重眼损伤/眼刺激：造成严重眼损伤。
- 呼吸道或皮肤致敏：吸入可能导致过敏或哮喘病症状或呼吸困难。可能造成皮肤过敏反应。

- 生殖毒性：可能对生育能力或胎儿造成伤害。
- 特异性靶器官毒性——一次接触：对器官造成损害。可能造成昏昏欲睡或眩晕。
- 特异性靶器官毒性——反复接触：长期或重复接触会对器官造成损害。
