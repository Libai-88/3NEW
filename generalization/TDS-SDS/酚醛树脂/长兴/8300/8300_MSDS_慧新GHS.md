## 2. 危险品宣告

该产品为液体状，具危险性。如吸入会影响身体健康，并可致过敏性反应。与皮肤接触或会出现斑点、水肿等症状。

**危险性类别：** 易燃液体类别3、呼吸道致敏物类别1、严重眼损伤/眼刺激类别1、急性经口毒性类别4、皮肤腐蚀/刺激类别2、皮肤致敏物类别1、吸入危害类别2、致癌物质类别2、危害水生环境-长期危险类别3

**信号词：** 危险

**危险性说明：**

| 代码 | 说明 |
|---|---|
| H226 | 易燃液体和蒸气 |
| H302 | 吞咽有害 |
| H315 | 造成皮肤刺激 |
| H317 | 可能造成皮肤过敏反应 |
| H318 | 造成严重眼损伤 |
| H350 | 可能致癌 |
| H335 | 可能造成呼吸系统刺激 |
| H336 | 可能造成困倦或晕眩 |

**防范说明：**

预防措施：
- P201 使用前取得专用说明
- P210 远离热源/火花/明火/热表面，禁止吸烟
- P271 只能在通风良好的环境使用
- P280 使用防护手套、目镜、脸部防护具
- P240 将容器和回收设备接地
- P241 使用防爆电气
- P242 只能使用不产生火花的工具
- P243 防止静电放电的措施
- P261 避免吸入烟雾/蒸气/喷雾
- P270 使用本产品时不要进食、饮水或吸烟
- P272 受沾染的工作服不得带出工作场地

事故响应：
- P305+P351+P338 如进入眼睛：用水小心冲洗几分钟，如戴隐形眼镜且方便取出，取出隐形眼镜，继续冲洗
- P308+P313 如接触到或有疑虑：求医/就诊
- P310 立即呼叫解毒中心或医生
- P370+P378 火灾时：使用抗溶性泡沫或正常蛋白泡沫灭火
- P302+P352 如果在皮肤上：用大量的水和肥皂冲洗
- P333+P313 如发生皮肤刺激或皮疹：求医/就诊
- P362+P364 脱掉所有沾染的衣服，清洗后方可重新使用
- P301+P312 如食入：如果感觉不适，呼叫中毒控制中心或就医
- P303+P361+P353 如皮肤（或头发）沾染：立即去除/脱掉所有沾染的衣服，用水清洗皮肤/淋浴
- P304+P340 如误吸入：将受害人转移到空气新鲜处，保持呼吸舒适的休息姿势
- P330 漱口

安全储存：
- P403+P235 存放在通风良好的地方，保持低温
- P405 存放处必须加锁

废弃处置：
- P501 处置内装物/容器按照当地规定

## 4. 急救措施

如有任何疑问或症状持续的情况，请寻求医生的帮助。

| 途径 | 措施 |
|---|---|
| 皮肤接触 | 脱去污染的衣服，用肥皂水及清水彻底冲洗皮肤，或用个人皮肤清洁剂清洗。若症状持续请就医 |
| 眼睛接触 | 立即翻开上下眼睑，用流动清水或生理盐水冲洗至少15分钟，如仍感刺激，就医 |
| 吸入 | 迅速脱离现场移到空气新鲜处，保持呼吸道畅通，如呼吸困难，给输氧，如呼吸停止，立即进行人工呼吸，就医 |
| 食入 | 如果意外吞下，不要催吐，就医 |

## 5. 消防措施

| 项目 | 内容 |
|---|---|
| 危险特性 | 其蒸气与空气形成爆炸性混合物，遇明火、高热能引起燃烧爆炸。蒸气比空气重，能在较低处扩散到相当远的地方，遇明火易引起回燃。若遇高热，容器内压增大，有开裂和爆炸的危险。流速过快，容易产生和积聚静电 |
| 有害燃烧产物 | CO、CO2 |
| 灭火方法及灭火剂 | 可用泡沫、二氧化碳、化学干粉、砂土扑救 |
| 灭火注意事项 | 火会引起浓厚的黑烟，暴露于分解的物质会对身体有害。消防人员必须使用通气式面罩或正压自给式呼吸器。火场中的密闭容器必须用水冷却。切勿让灭火后产生物质流入下水道或排水管 |

## 6. 泄漏应急处理

| 项目 | 内容 |
|---|---|
| 个人注意事项 | 为个人安全着想，工作时需佩带可抗溶剂的保护手套 |
| 环保措施 | 如出现泄漏，需用耐燃物料如沙、泥等覆盖于外泄位置。产品需远离火种，操作时切勿吸烟。如产品外泄后接触水源、贮水池，或对该地点或农作物造成污染，通知有关部门负责单位 |
| 清理方法 | 因产品与空气接触会释放二氧化碳，需以开放容器收集及弃置废品。弃置前需等待数天，废品最终需经焚化处理 |

| 项目 | 内容 |

## 11. 含毒性物质信息

过量或长期与皮肤接触会造成天然油脂流失或非过敏性皮肤炎。暂无有关主要物质的毒性浓度指引。急性毒性、皮肤刺激/腐蚀、呼吸或皮肤过敏、严重损伤/刺激眼睛：无相关资料。

## 12. 生态学资料

工作环境需符合当地环保条例，避免随意处理产品，破坏生态环境。生态毒性、持久性和降解性、潜在的生物积累性、土壤中的迁移性、其他不良反应：均无相关资料。

## 13. 废弃处置

使用后的空桶在弃置前需先以异丙醇/氨水/清水的混合溶剂清洗干净，弃置程序需符合当地环保条例。
