### 应用领域
- **罐头内涂层**：主要用作高分子量环氧树脂的固化树脂；建议配方30–45% PR 612 + 70–55% BECKOPOX EP 307/EP 309（按固含量），烘烤后获得高柔韧性、良好附着力和耐化学性漆膜，用于食品和奢侈品行业罐、管及包装容器内涂层。可加酸性催化剂（最高6% ADDITOL® XK 406，基于固体树脂）提高反应性和附着力（尤其铝材），并提高硬度与耐硫化物性；添加5–10% PHENODUR® PR 308（按固含量）可增强金黄色调。
- **耐化学腐蚀防护涂层**：可作唯一基料用于刚性底材上较脆的高耐性烘烤瓷漆（容器、设备、管道内衬）；加5–25%聚乙烯醇缩丁醛可改善柔韧性而不损害耐化学品性；多层涂装时首层不完全固化。
- **电线涂层、电绝缘漆**：推荐与（聚）乙烯醇缩甲醛树脂组合，配比约 **40:60**；溶剂混合物含苯酚/甲酚和醇类；多层施工，300–350℃固化。

### 加工
- **溶剂**：乙二醇醚、酯类、双丙酮醇和酮类。
- **颜料**：可用惰性颜料/填料（钛白粉、氧化铁红、滑石粉等）着色，优选耐酸耐碱体系。
- **烘烤条件**：180–220℃、30–10分钟；上限220℃（超过则柔韧性下降）；薄膜罐涂层10–15 min / 190–200℃，或90秒 / 265℃冲击干燥；良好耐化学品性起始温度190℃。
- **催化**：酸性催化剂可提高反应活性和硬度，改善铝材和马口铁上附着力。

### 储存
- ≤25℃、原装容器下储存稳定性 **730天**；到期经QC留样检测可延长并更新COA。

### 鉴别特征
- 反应活性低于 PR 217、PR 285、PR 401、PR 515、VPR 1775、VPR 1776；粘度低于 PR 217、PR 285、PR 373、PR 722、PR 723。

### 2. 危险性概述
- **外观**：棕色液体，丁醇味
- **GHS分类**：易燃液体3类；致癌物1A类；特异性靶器官毒性（一次接触）3类；皮肤腐蚀/刺激2类；严重眼损伤/眼刺激1类；皮肤致敏1A类
- **警示词**：危险
- **H声明**：易燃液体和蒸气；可能致癌；可引起呼吸道刺激；可引起昏睡或眩晕；造成皮肤刺激；造成严重眼损伤；可能导致皮肤过敏反应
- **健康危害**：急性经口（大鼠）LD50 2500 mg/kg；经皮（兔）LD50 >2000 mg/kg；吸入（大鼠4h）LC50 >5 mg/L；直接接触致严重眼刺激和中度皮肤刺激；反复皮肤接触可致过敏性皮肤反应。
- **其他危害**：过热、污染或阳光直射可能导致聚合反应；避免接触强酸、不与氧化剂共储。

### 4. 急救措施
- **吸入**：转移至新鲜空气处，呼吸困难输氧，症状持续就医。
- **皮肤接触**：立即脱去污染衣物和鞋，大量水冲洗，就医。
- **眼睛接触**：大量水冲洗至少15分钟，立即就医。
- **食入**：立即打电话请医生，仅医生指导下诱吐，勿给昏迷者喂食。

### 5. 消防措施
- 灭火介质：水、泡沫、CO₂或干粉；柱状水可能无效，避免高压水枪；火中容器喷水冷却。消防员佩戴自备空气呼吸装置、穿完全防火衣。

### 6. 泄漏应急处理
- 人员防护：接触限值未知时戴正压自备空气呼吸器；穿不渗透靴。
- 清除：惰性吸收材料覆盖→收入废物回收容器→水冲洗溢出区→移走着火源。

### 7. 操作处置与储存
- **操作**：远离热源/火花/明火；容器密闭、接地；防爆电器、无火花工具、防静电；戴防护手套和护眼/面罩；通风良好处操作；避免接触强酸、不与氧化剂共储；避免过热、污染或阳光直射以防聚合。
- **储存**：凉爽、干燥、通风良好，容器密封；防静电、装卸料接地；远离热源和直射阳光；储存温度约23℃（保持品质稳定）。

### 8. 接触控制与个体防护
- **接触限值**：丁醇—中国OELHA 100 mg/m³（TWA）/150 mg/m³（STEL），ACGIH 20 ppm（TWA）；甲醛—中国OELHA 0.5 mg/m³（Ceiling），ACGIH 0.3 ppm（Ceiling）。
- **工程控制**：尽可能密闭系统加工；非密闭须覆盖与局部抽风。
- **呼吸防护**：全脸式面罩，A型有机蒸汽过滤筒（BP>65℃）。
- **手防护**：长期接触—NBR >0.38mm（>480分钟）；短期/防溅—NBR 0.12mm（最长120分钟）；天然橡胶、聚乙烯醇手套不适用。
- **眼睛/身体防护**：设洗眼喷水器与安全淋浴器；防化学喷溅眼罩/面具；密封手套、防护衣。
