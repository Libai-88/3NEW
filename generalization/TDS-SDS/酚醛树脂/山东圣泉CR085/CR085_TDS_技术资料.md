# CR085 技术资料（TDS）

**圣泉集团 SQ GROUP — TECHNICAL DATA SHEET**

## 一、产品特点

圣泉 CR 085 产品是一种烷基酚醚化酚醛树脂，溶剂为丁醇。高活性、柔韧性较好。溶于苯类、丁醇等溶剂，具有良好的稳定性、相容性、耐水性和耐化学腐蚀性。

## 二、应用领域

- 适用于卷材涂料系统
- 适用于 BADGE 及 BPA-NI 应用
- 不建议使用催化剂

## 三、产品指标

| 项目 | 指标 |
| --- | --- |
| 产品型号 | CR085 |
| 外观 | 红棕色透明液体 |
| 粘度 (CP/25℃) | 200-300 |
| 溶解性 | 1:4 甲苯清 |
| 固体含量 | 56-66% |

## 四、典型性能

（测试条件：搭配 6 系或 9 系环氧，酚醛与环氧固含比为 1:4-5，205℃ 下烘干 12 分钟）

| 项目 | 结果 |
| --- | --- |
| 搭配环氧固化颜色 | 深色 |
| MEK 摩擦试验 | ≥100 次 |
| 耐水蒸煮性（127℃，60min） | 通过 |

## 五、包装和储存

- **包装形式**：液体树脂，200KG/桶，化工桶包装
- **储存条件**：树脂必须储存在阴凉通风干燥处（25℃ 以下），避免阳光直射，远离热源；在储存运输过程中，树脂应避免接触热源或激烈碰撞
- **产品有效期**：1 年
- 具体储运措施详见 MSDS
