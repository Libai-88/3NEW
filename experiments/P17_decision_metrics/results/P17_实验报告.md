# P17 实验报告：T 弯决策指标转型（风险闸门与选择性预测）

**日期**：2026-11-26  
**实验目录**：`experiments/P17_decision_metrics/`  
**状态**：10 seeds full 完成；C1/C2 已按预注册门槛判定。  
**外部 reviewer**：不可用；本报告是本地确定性分析，审计状态为 `PROVISIONAL_LOCAL_AUDIT`，不能声称跨模型 acquit。  
**约束**：短期无新数据；不改原始数据、不改切点、不新增特征、不重训新模型族。只把已冻结模型的 OOF 概率转成决策指标。

## 1. 结论先行

**决策指标转型可行，但没有免费提升。** 同样的 OOF 概率，换成“放行 / 判高 / 复测”的决策规则后，风险指标可以大幅改善，但改善来自明确的复测量和误判高代价，不是模型变准了。

- **C1 失败（严格门槛）**：`three_way` 把 false release 从 `21.41%` 压到 `3.66%`（相对下降 `82.9%`），复测率 `21.40%`，高档 recall `84.79%`（+6.20 pp），QWK `0.5908`（+0.0240）；但 operational cost 只从 `0.9196` 降到 `0.8824`（−`0.0372`），没有达到预注册的 ≥`0.10`。同时 `pred_high_rate` `39.40%` 超过 anti-claim 上限 `38.59%`，说明风险下降有一部分来自“更多判高”。
- **C2 失败（严格门槛）**：`selective τ=0.60` 的 coverage `81.16%`、false release `14.93%`（相对下降 `30.26%`）、QWK `0.6297`（+0.0629）均达标；但全体高档 recall 从 `78.59%` 降到 `70.70%`（−7.89 pp），超过 ≤0.05 的允许下降。把 abstain 视为复测后，**接受样本中的高档 recall 为 `82.53%`（+3.94 pp）**，但这是补充口径，不能改写预注册 C2 的失败。
- **现有 `cost` 策略不可用**：`p09.cost_matrix` 的“过度预测多罚 2 倍”目标与 false release 风险不一致；它把 false release 推到 `37.32%`，operational cost 升到 `1.0738`，QWK 降到 `0.5393`。这说明**决策层的目标函数必须和业务风险对齐**，不能直接沿用旧的等级代价矩阵。

**一句话选择**：
- 若“坏货放行”是首要风险、且能接受约 21% 复测：`three_way` 是风险闸门，不是免费提升；它会把 false release 压到约 3.7%，但 false reject 升到 `25.4%`、高档 precision 降到 `50.8%`。
- 若要在风险和 QWK 之间取平衡、且能接受约 19% 复测：`selective τ=0.60` 更均衡；它把 false release 降到 `14.9%`，QWK 提到 `0.630`，false reject 降到 `12.8%`，但全体高档 recall 降到 `70.7%`（14.4% 的高档样本转复测）。

## 3. 主结果（full8，10 seeds）

| 策略 | coverage | test rate | false release | false reject | 全体 high recall | 接受样本 high recall | high test rate | high precision | pred high rate | QWK | operational cost |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| `argmax` | 100.0% | 0.0% | 21.41% | 18.09% | 78.59% | 78.59% | 0.0% | 57.40% | 32.36% | 0.5668 | 0.9196 |
| `three_way` | 78.60% | 21.40% | **3.66%** | 25.39% | 84.79% | **95.87%** | 11.55% | 50.80% | 39.40% | 0.5908 | 0.8824 |
| `selective τ=.60` | 81.16% | 18.84% | 14.93% | **12.78%** | 70.70% | 82.53% | 14.37% | **63.11%** | 26.45% | **0.6297** | **0.8336** |
| `high_guard T=.35` | 100.0% | 0.0% | 15.21% | 25.39% | 84.79% | 84.79% | 0.0% | 50.80% | 39.40% | 0.5445 | 0.9409 |
| `cost` | 100.0% | 0.0% | 37.32% | 8.43% | 62.68% | 62.68% | 0.0% | 69.76% | 21.23% | 0.5393 | 1.0738 |
| `cost_abstain` | 97.67% | 2.33% | 34.23% | 8.22% | 60.99% | 64.07% | 4.79% | 69.73% | 20.66% | 0.5574 | 1.0189 |

**读法**：`three_way` 的 false release 最低，但它是“高召回 + 高复测 + 低 precision”的组合；`selective` 的 QWK、false reject、precision 更好，但会把 14.4% 的高档样本转复测，所以全体 high recall 下降。两者都不是“模型更准”，而是把不确定性显式化。

### 3.1 C1 细节

- cost：`0.9196 → 0.8824`，配对差 `−0.0372`，sd `0.0464`，t p `0.0319`，Wilcoxon p `0.0391`，7/10 seeds 改善。
- false release：`0.2141 → 0.0366`，相对下降 `82.9%`，p `8.24e-11`，10/10 seeds 改善。
- test rate `21.40%`（约 64/301），低于 35% 上限。
- high recall `+6.20 pp`，但 false reject `+7.30 pp`、high precision `−6.60 pp`；`pred_high_rate` `39.40%`，略高于 anti-claim 上限 `38.59%`。
- **失败原因不是“策略无效”，而是“代价下降幅度不够大”**：每避免 1 个 false release，净节省约 0.89 个相对成本单位（已扣掉复测和误判高）。按当前示例权重，净收益是正的，但没有达到预注册的 0.10。

### 3.2 C2 细节

- coverage `81.16%`，test `18.84%`；false release `0.2141 → 0.1493`，相对下降 `30.26%`，p `1.37e-5`，10/10 seeds 改善。
- QWK `0.5668 → 0.6297`（+0.0629，p `1.80e-5`，10/10）。
- **全体 high recall** `0.7859 → 0.7070`（−7.89 pp，p `1.30e-5`）；这是 C2 失败的直接原因。
- 补充口径：接受样本 high recall `0.7859 → 0.8253`（+3.94 pp，p `6.28e-4`，9/10）；high test rate `14.37%`。如果业务把“abstain = 转复测，不是漏检”，这个口径更贴近实际操作；但它是 post-hoc 补充，不是预注册 C2 的通过。
- false reject `18.09% → 12.78%`，high precision `57.40% → 63.11%`；pred high `32.36% → 26.45%`，anti-claim 通过。

| selective | 0.50 | 96.41% | 3.59% | 19.86% | 77.61% | 0.5844 | 0.9040 |
| selective | 0.60 | 81.16% | 18.84% | 14.93% | 70.70% | 0.6297 | 0.8336 |

## 5. 解释与边界

### 5.1 为什么 `three_way` 的 cost 只降了 0.037？

因为 false release 的下降伴随两类成本：

1. 21.4% 样本进入复测，约 64/301；
2. false reject 从 18.1% 升到 25.4%，约多 17 个 low/mid 被判高。

按示例权重（false release 10、false reject 3、复测 1），false release 避免了约 12.6 个高档样本，毛收益约 126 单位；复测约 64 单位、误判高约 50 单位，净收益约 11 单位/301，即 `−0.037/样本`。**这说明“false release 权重 10”下净收益仍为正，但被复测和误判高吃掉了大部分。** 该权重是相对口径，不是客户确认金额。

### 5.2 为什么 `selective` 的全体 high recall 下降？

因为 selective  abstain 的样本里包含困难的高档样本；在“全体高档”口径下，它们没有被直接判高，所以算未命中。若业务把 abstain 送复测，则接受样本的 high recall 反而升到 `82.53%`，但复测率为 `14.37%`（高档样本口径）。**这两个口径不能混用**：C2 用全体口径，所以 FAIL；补充口径只用于运营解释。

### 5.3 为什么旧的 `cost` 策略更差？

`p09.cost_matrix(3)` 的设计是“过度预测比欠预测多罚”，它优化的是等级代价，不是“坏货放行”。在本数据上它把预测压向低等级，false release 升到 `37.32%`，QWK 降到 `0.5393`。这说明**决策矩阵必须按业务风险重新定，而不能默认沿用历史 cost matrix**。

## 6. 局限

- 301 条 T 标签，三类 `33 / 197 / 71`；低档只有 33 条，false reject 的估计方差大。
- 10 seeds 是重复交叉验证，不是 10 个独立外部验证；置信区间应按 seed 配对差解释，不能当作部署置信区间。
- 成本权重（false release 10 / false reject 3 / test 1）是**示例相对权重**，不是客户确认金额；换权重会改变最优策略。
- 阈值是预注册固定值，没有在测试折上调参；因此不能排除“换阈值/换代价后 C1 会过”的可能，但那是下一轮预注册实验，不是本轮的 post-hoc 补救。
- 只覆盖 T 弯；MEK/水煮的决策指标转型未做。
- OOF 概率来自冻结模型，不是生产环境实时概率；没有做概率校准和分布漂移监测。
- 无外部 reviewer；`PROVISIONAL_LOCAL_AUDIT`，不能声称跨模型 acquit。

## 7. 建议

1. **保留决策指标转型**：它把“QWK 好不好”变成“放行/复测/误判高的代价”，对业务更有用；本轮证明可行，但没有免费提升。
2. **若风险优先**：把 `three_way` 作为候选风险闸门，先在离线/小批量影子模式运行，记录复测率、false reject、高档 precision；不要直接全量上线。
3. **若平衡优先**：`selective τ=0.60` 是更均衡的候选，QWK `0.630`、false release `14.9%`、false reject `12.8%`；但必须接受 18.8% 复测和全体 high recall 下降 7.9 pp。
4. **不要部署 `cost` / `cost_abstain`**：它们与 false release 目标不一致。
5. **下一步不是继续搜 FTIR 子集**：在 301 条数据上继续调特征/块权重只会得到 ±0.01 QWK 波动；要提升 QWK 到 0.65+，需要新 T 标签、重复测量、标签噪声估计或外部系列验证。
6. **下一轮预注册**：若业务确认成本权重，做 `P18`：在训练折内选阈值（nested），把代价权重、复测容量、false reject 上限作为预注册参数；本轮不把 post-hoc 阈值搜索写成确认结果。
