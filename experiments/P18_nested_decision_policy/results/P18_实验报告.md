# P18 实验报告：嵌套校准决策策略

**日期**：2026-11-26  
**实验目录**：`experiments/P18_nested_decision_policy/`  
**数据**：`合并版数据集.xlsx`，T 弯 301 条环氧酚醛，切点 `[15,20]`  
**协议**：外层 `StratifiedGroupKFold(5)`，内层 `StratifiedGroupKFold(4)`，10 seeds  
**模型**：P16 `full8`（183 + 8 FTIR），C=2.0、w=1 固定；不改特征、不改模型族  
**外部 reviewer**：`REVIEW_UNAVAILABLE`；本报告是本地确定性分析，审计状态 `PROVISIONAL_LOCAL_AUDIT`  
**结论先行**：**C1/C2 均未通过预注册门槛；当前 301 条 T 标签下没有找到可部署的嵌套决策策略。** 均值层面的 C1 看起来接近达标，但 10 个 seed 中只有 3 个同时满足全部约束，不能升级为成功。  

## 1. 本轮做了什么

P17 的阈值是固定的，概率未校准，成本权重是示例值。P18 把这些都放进严格嵌套流程：

1. 每个外层训练折内再做 4 折分组 OOF；
2. 温度缩放只在**内层 OOF** 上拟合，外层测试只应用；
3. `three_way` 和 `selective` 的阈值只在**内层 OOF** 上选，外层标签不参与；
4. 主设置 `false_release=10 / false_reject=3 / retest=1`，复测容量 25%；
5. 另跑 `false_release ∈ {5,10,20}` × `false_reject ∈ {2,3,5}` × `capacity ∈ {15%,25%,35%}` 的敏感性。

运行规模：47 个策略臂、10 seeds、3010 条外层 OOF、2200 条逐折阈值记录、50 条校准记录；最终重跑 **48.7 s**（2 vCPU，无 GPU；首次 53.8 s，OOF/阈值/逐 seed 的 SHA256 与重跑一致，确认删除死代码未改变结果）。

## 2. 主结果

`full8`，10 seeds 均值：

| 策略 | false release | 复测率 | 全体 high recall | pred high | high precision | 决策代价 | QWK | 可行折 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| `argmax` | 21.27% | 0% | 78.73% | 32.09% | 57.95% | 0.9073 | 0.5740 | — |
| P17 `three_way` 固定 | 3.66% | 20.23% | 84.93% | 38.97% | 51.49% | 0.8568 | 0.5935 | — |
| **P18 `three_way` 嵌套+校准** | **4.65%** | **22.16%** | **78.31%** | **34.58%** | **53.46%** | **0.8146** | **0.6070** | **11/50** |
| P17 `selective` 固定 | 15.35% | 17.48% | 70.85% | 26.61% | 62.83% | 0.8339 | 0.6277 | — |
| **P18 `selective` 嵌套+校准** | **16.48%** | **12.99%** | **73.52%** | **29.00%** | **59.87%** | **0.8684** | **0.6093** | **0/50** |

### C1：均值接近，但 seed 级不通过

C1 要求 false release ≤5%、复测 ≤25%、high recall 下降 ≤5 pp、`pred_high_rate` ≤38.59%、决策代价下降 ≥0.02、high precision 下降 ≤5 pp，且至少 8/10 seeds 同时满足。

10-seed 均值层面：

- false release `4.65%`，test `22.16%`；
- high recall `78.31%` vs `78.73%`，仅 `−0.42 pp`；
- pred high `34.58%`，低于 `38.59%` 上限；
- high precision `53.46%` vs `57.95%`，下降 `4.49 pp`；
- 决策代价 `0.8146` vs `0.9073`，下降 `0.0927`（p `0.0025`）；
- false release 配对 p `7.05e-10`，10/10 seeds 改善。

**但 seed 级 gate 只有 `3/10`：**

- 4 个 seed 的 false release 超过 5%：`202 / 1234 / 5678 / 9999`，最高 `7.04%`；
- 4 个 seed 的 high precision 下降超过 5 pp：`777 / 2718 / 5678 / 9999`；
- `2718` 的决策代价没有下降，`1618` 的复测率超过 25%。

因此 **C1 pass=false**。均值是“看起来能过”，不是“稳定能过”；不能把 10-seed 均值包装成部署结论。

### C2：selective 仍不达标

C2 要求 coverage ≥0.70、false release 相对下降 ≥30%、high recall 下降 ≤5 pp、QWK 下降 ≤5 pp、`pred_high_rate` ≤38.59%，8/10 seeds。

- coverage `87.01%`，达标；
- false release `16.48%` vs `21.27%`，相对下降 **22.52%**，低于 30%；
- high recall `73.52%` vs `78.73%`，下降 **5.21 pp**，超过 5 pp；
- QWK `0.6093` vs `0.5740`，QWK 有提升，但不能抵消前两项；
- seed gate **1/10**。

**C2 pass=false**。这不是“只差一点 recall”的问题：false release 相对下降也没到预注册的 30%。

## 3. 最关键的限制：内层约束经常无可行解

阈值选择要求内层同时满足：

- false release ≤5%；
- test ≤cap；
- high recall ≥内层 argmax −5 pp；
- pred high ≤内层真实高档率 +15 pp；
- high precision ≥内层 argmax −5 pp；
- coverage ≥70%。

实际结果：

- `three_way` 主设置：50 个外层折中只有 **11 个**有可行阈值；平均每个 seed 有 **3.9/5** 折只能选“最不坏”的 fallback；
- `selective` 主设置：**0/50** 折有可行阈值；全部是 fallback。

这意味着 P18 的阈值不是“约束最优解”，而是**在不可行约束下的最小违约解**。报告必须把这一点写清楚；否则会把 fallback 误读成“嵌套约束选择成功”。

## 4. 校准与成本敏感性

### 校准

温度缩放只用内层 OOF 拟合，外层只应用。50 个折：

- T 均值 `2.964`，46/50 折落在上界 `3.0`；说明模型概率被 class-weight/ordinal 结构压得偏尖，温度校准在边界上仍有收益；
- NLL `1.464 → 0.961`；
- ECE `0.145 → 0.089`。

校准改善了概率质量，但没有把决策指标推过 C1/C2；不能把“ECE 降低”当成决策策略成功的替代证据。

### 成本敏感性

`three_way` 在 21 个成本/容量组合中：

- 主容量 25% 下，`false_release=5/10/20` 选出的阈值和 false release/test/high recall 完全相同，只有报告代价随权重变化；
- 容量 35% 时 false release 可降到 `3.38%`，但 test `26.81%` 超过主设置 25%；
- 容量 15% 时 false release `6.34%`、test `14.29%`、high recall `82.96%`，false release 反而更高；
- 没有一组同时满足 false release ≤5%、test ≤25%、high recall 不降 >5 pp。

`selective` 在 21 个组合中全部无可行折，false release 在 `15.77%–17.75%`，无法接近 30% 相对下降。

结论：**当前约束下，成本权重不是主要自由度；容量约束和概率质量才是。** 不能通过换一个成本权重“调出”成功。

## 5. 与 P17 的关系

- P17 `three_way` 的 false release 更低（`3.66%`），但 pred high `38.97%` 超过 anti-claim，成本仅降 `0.0505`；
- P18 `three_way` 的 pred high 更低（`34.58%`）、成本降幅更大（`0.0927`）、QWK 更高（`0.6070`），但 false release 更高（`4.65%`）、high recall 更低（`78.31%`）；
- 两者没有支配关系。P18 不是 P17 的升级版，而是一次失败的“嵌套化”尝试。
- P18 `selective` 的 coverage/high recall 比 P17 固定版好，但 false release 更差、QWK 更低；同样不能替代。

## 7. 结论与下一步

**P18 的结论是负面的：嵌套阈值 + 温度校准没有产生稳定可部署的 T 弯决策策略。** 继续在 301 条数据上调阈值/成本权重，预计只会得到 seed 间摆动，而不是稳定收益。

下一步应按 P19 走数据层：

1. 44 条未测环氧酚醛 T 的主动补测；
2. 20–30 条分层重复 T 测试，估计 ICC/κ 和标签噪声地板；
3. 若业务确认成本权重，再考虑 P18-B：预注册“硬风险 fallback”或 conformal risk control，而不是 post-hoc 改阈值。
