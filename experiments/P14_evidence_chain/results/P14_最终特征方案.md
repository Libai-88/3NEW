# P14 最终特征与模型方案

## 结论

在 345 条环氧酚醛主体系、固定标签切点、`StratifiedGroupKFold(5)` 按 `formula_id` 分组、10 个 seeds 的条件下，最终方案如下。T 的数值用 **nested C 选择** 作为保守估计；括号内是固定 C=2 的点估计。

| 目标 | 特征集 | 维度 | 模型/决策 | QWK | 高档 recall | 代价 |
|---|---|---:|---|---:|---:|---:|
| T | 183 + FTIR7（去掉 `ftir_oh_epox`） | 190 | ordinal logistic，C=2，argmax | **0.5707 ±0.0252**（固定 C=2：0.5797 ±0.0225） | 0.7901 | 0.6781（固定：0.6645） |
| MEK | base183 | 183 | ordinal logistic C=1 + cost-anchor | 0.6424 ±0.0225 | 0.7697 | 0.9164 |
| 水煮 | base183 | 183 | ExtraTrees multiclass，argmax | 0.4695 ±0.0234 | 0.6790 | 0.9476 |

三目标平均：QWK **0.5609**（固定 C=2 为 0.5639），P12 为 0.5485；平均高档 recall 0.7463，P12 0.7427；平均代价 0.8474，P12 0.8705。

## T 的最终配置

- 特征矩阵：`experiments/P13_feature_opt/data/feature_matrix_p13_t_ftir7.csv`（345×190，T 用 301 行）。
- 183 个 base 特征 + 7 个 FTIR：`ftir_oh_phen`、`ftir_meoh_phen`、`ftir_aroc_phen`、`ftir_coc_all`、`ftir_arsub_all`、`ftir_ch_all`、`ftir_co_all`。
- 预处理：median imputer + missing indicator，StandardScaler。
- 模型：`sklearn.linear_model.LogisticRegression`，ordinal cumulative，C=2.0，l2，class_weight=balanced，lbfgs，max_iter=3000。
- 决策：`argmax` 累积概率。
- 嵌套内层 C 网格：0.5 / 1.0 / 1.5 / 2.0；内层 3-fold grouped CV。

## 证据链

### 1. 数据审计

- 主数据 SHA256：`753afe8e97a77d1f39d4f852857da5cc204f28c445d3fbfcb3ddf7ff2d67f3f9`。
- 主体系 345 条，T 301 条；T 类别 0/1/2 = 33 / 197 / 71。
- 原料 FTIR：10 条，93 °C 真空干燥 7 天，纯固态、无溶剂；OMNIC 已做 10–100 %T 逐谱归一化，不再二次归一化。
- T 190 矩阵的 FTIR 缺失：`ftir_oh_phen` 7、`ftir_meoh_phen` 31、`ftir_aroc_phen` 7，其余 0；由训练折内 median imputer 处理。

### 2. 10-seed C 网格（固定 C）

T 基线 183 与 191（183+FTIR8）在 C=0.1–2.0 上的 10-seed 均值：

| C | base183 QWK | FTIR8 QWK | 差值 |
|---:|---:|---:|---:|
| 0.5 | 0.5417 | 0.5563 | +0.0146 |
| 1.0 | 0.5516 | 0.5695 | +0.0178 |
| 1.5 | 0.5475 | 0.5737 | +0.0262 |
| 2.0 | 0.5517 | 0.5740 | +0.0223 |

C=1.5–2.0 是平台；C=2 的绝对 QWK 最高，C=1.5 的差值最大但绝对值略低。C=2 被选为最终参数。

### 3. Nested C 选择（防参数选择泄漏）

外层 5 折，内层 3 折 grouped CV，C 从 0.5/1/1.5/2 中选：

- base183：0.5451 ±0.0227。
- FTIR8 191：0.5599 ±0.0275；差值 +0.0198（p=0.0095，8/10 正）。
- **FTIR7 190**：**0.5707 ±0.0252**；差值 **+0.0256**（p=0.0046，Wilcoxon p=0.0059，9/10 正，95% seed-level CI [0.0101, 0.0410]）。

这是最终采用的保守估计；固定 C=2 的 0.5797 是参数已选后的点估计，偏乐观。

### 4. 模型族比较（T，10 seeds）

| 模型 | 183 base | 190 FTIR7 |
|---|---:|---:|
| ordinal logistic C=2 | 0.5517 | **0.5797** |
| ordinal XGBoost | 0.4271 | 0.4346 |
| multiclass XGBoost | 0.4182 | 0.4248 |

ordinal logistic 明显优于两种 XGBoost 方案；C=2 是 10-seed 绝对 QWK 最高点。说明「模型选择最适配」是 ordinal logistic，不是树模型。

### 5. FTIR 子集与 drop-one

drop-one（C=2，10 seeds）相对 full8 的差值：

- 去掉 `ftir_meoh_phen`：−0.0105（最关键）。
- 去掉 `ftir_oh_epox`：**+0.0057**（中性偏害）。
- 去掉 `ftir_aroc_phen`：+0.0016；去掉 `ftir_co_all`：+0.0015；去掉 `ftir_arsub_all`：+0.0003。
- 去掉 `ftir_oh_phen`：−0.0036；去掉 `ftir_ch_all`：−0.0043；去掉 `ftir_coc_all`：−0.0003。

因此最终去掉 `ftir_oh_epox`，保留 7 个；190 维的 QWK 0.5797，优于 191 的 0.5740 和 core4 的 0.5794。注意这是同数据上的 post-hoc 子集选择，P14 用 nested CV 复核后仍为正，但不能当作独立验证。

### 6. FTIR 置换零假设

把 7 个 FTIR 列作为整块在样本间置换，保留样本内 profile、破坏样本-标签关联；20 次置换 ×5 seeds：

- 观测均值 0.5729。
- 零分布 0.5308 ±0.0133，最大 0.5503。
- 经验 p = 0.0476（20 次置换的分辨率下限）。

说明 FTIR 块的增益不是随机置换能达到的。

### 7. Bootstrap

- 按 `formula_id` 组重采样，每 seed 2000 次：固定 C=2 的 delta 均值 0.0279，整体 95% 区间 [−0.0360, 0.0964]；样本级重采样较宽，因为组内样本高度相关，不能把区间收窄当成强显著。
- 按 seed 做配对 t 区间：固定 C=2 delta +0.0280，95% CI [0.0110, 0.0449]，p=0.0047；nested delta +0.0256，95% CI [0.0101, 0.0410]，p=0.0046。

因此证据强度是「10 seeds 下稳定正增益、置换检验过 0.05、但样本级 bootstrap 仍宽」，不是「已证明普适」。
