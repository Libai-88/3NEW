## 第三部分：危险性概述

**紧急概述**：白色粉末，带有轻微气味。泄漏时湿滑。空气中的高浓度粉尘可能存在粉尘爆炸危险。在此情况下，远离热源、火花和明火。所有设备需接地。

**潜在健康影响**

| 接触途径 | 影响 |
|---|---|
| 眼睛 | 可能引起轻微刺激 |
| 皮肤 | 反复或长期接触可能引起皮肤刺激 |
| 摄入 | 正常工业使用无危害 |
| 吸入 | 可能刺激鼻、喉和呼吸道 |
| 慢性影响 | 未知 |
| 致癌性 | NTP：未列出；IARC：未列出；OSHA：未列出 |
| 加重病情的条件 | 未知 |

|---|---|

## 第六部分：泄漏应急处理

- 移除点火源。
- 扫起材料。避免产生粉尘。
- 如材料处于熔融状态，设法围堵泄漏物直至冷却凝固，然后刮起并妥善处置。
- 防止泄漏物和清洁径流进入市政下水道和开放水体。

## 第七部分：操作处置与储存

- 在适当的储存条件下保存。"适当的储存条件"指密封容器中，存放于阴凉（7 至 32 ℃ [45 至 90 °F]）、干燥、通风良好的区域。
- 避免过高温度、冻结条件及点火源。
- 避免湿气和潮气。不要污染产品。
- 细粉/粉尘可能引起眼睛和呼吸道刺激。使用时应保证充分通风。
