## 二、危害标识

### 紧急概况

- 该混合物整体未被评估。所有成分均被结合，出厂状态下有害暴露可能极低
- **加热或加工时可能释放挥发物**，最终用户（加工商）必须采取必要的预防措施（机械通风、呼吸防护等）
- 火灾条件下可能释放 **氯化氢（HCl）** 或 **一氧化碳（CO）**

### 分类

- 产品无需按照 EC 指令或相应国家法律贴标签
- 根据 EC 指令 67/548/EEC 或 1999/45/EC，不属于危险物质或混合物

### 潜在健康影响

| 暴露途径 | 影响 |
|----------|------|
| 吸入（树脂颗粒） | 可造成机械性刺激；加工温度下排放物可能引起刺激 |
| 摄入 | 预计无不良健康影响 |
| 眼睛接触 | 树脂颗粒可造成机械性刺激 |
| 皮肤接触 | 常规操作无异常皮炎危害 |

## 五、消防措施

| 项目 | 数值 |
|------|------|
| 闪点 | 736 °F（ASTM D1929） |
| 爆炸上限/下限 | 不适用 |
| 自燃温度 | 不适用 |

### 灭火介质

- **适用：** 水雾、干粉、泡沫、二氧化碳
- **禁用：** 无

### 特殊消防程序

- 佩戴正压式全面罩自给式呼吸器（SCBA）
- 固体聚合物难以燃烧，无外部热源时趋于自熄
- 燃烧时产生 **氯化氢（HCl）**
- 乙烯基树脂粉尘爆炸倾向极低，最低点火能量远高于淀粉、面粉等天然材料

### 有害燃烧产物

- 二氧化碳（CO₂）、一氧化碳（CO）、氮氧化物（NOx）、其他有害物质和烟雾

## 七、操作和储存

### 操作

- 采取措施防止静电积聚
- 仅在配有适当排风区域使用
- 材料可能造成湿滑条件

### 储存

- 保持容器干燥并紧闭，防止吸湿和污染

## 八、暴露控制/个人防护

### 工程措施

- 仅在设有适当排风的区域加热
- 在机器处提供适当的排风

### 个人防护装备

| 防护类型 | 要求 |
|----------|------|
| **呼吸防护** | 正常条件下可能不需要；如出现粉尘条件，佩戴适当的呼吸防护 |
| **眼睛/面部防护** | 带侧护罩的安全眼镜 |
| **手部防护** | 防护手套 |
| **皮肤和身体防护** | 长袖衣物 |
| **额外防护措施** | 安全鞋 |

### 残留氯乙烯单体（VCM）说明

- 本产品可能含有残留 VCM（CAS 75-01-4），含量 **低于 1 ppm（0.0001%）**
- 在充足通风的正常工作条件下，不太可能超过残留 VCM 的暴露限值
- 用户应采取必要预防措施（机械通风、局部排风、空气监测、呼吸防护等）
