## 第3节 — 危险性概述

**3.1 危险性分类**  
根据欧盟的标准，该产品不属于危险物品。

**3.2 对健康的潜在影响**

| 接触途径 | 影响 |
|----------|------|
| **吸入** | 无现有证据证明对身体有害 |
| **眼睛接触** | 粉尘的刺激，可引起刺痛和不适或疼痛；蒸气可引起轻微不适 |
| **皮肤接触** | 短暂接触刺激皮肤；长期或反复接触可能引起不适和部分红肿 |
| **吞咽** | 不大可能出现 |

## 第4节 — 急救措施

| 接触途径 | 急救措施 |
|----------|----------|
| **吸入** | 设法给予新鲜空气 |
| **眼睛接触** | 立即用大量清水冲洗。如果持续痛感请就医 |
| **皮肤接触** | 脱去污染衣物，用肥皂水清洗；如果疼痛刺激持续，清洗衣服方可重新使用 |
| **吞咽** | 如果病人有充分认识，冲洗口腔 |
| **给医师的建议** | 没有具体的解毒剂。治疗应针对病人的临床情况 |

## 第5节 — 消防措施

| 项目 | 内容 |
|------|------|
| **适合的灭火材料** | 水雾或细喷雾、干粉灭火器、二氧化碳灭火器、泡沫灭火器 |

| **特殊灭火程序** | 不要将泡沫或水直接进入燃烧熔融的材料，这可能会导致喷溅或者火势的扩大 |

- **材料释放或泄漏：** 切断火源，遵照政府规章清扫、收集处置
- **人身防护措施：** 穿戴合适的防护设备

---

## 第7节 — 操作处置与储存

**7.1 搬运操作**  
- 避免形成灰尘，远离明火、热量与火花
- 避免形成灰尘积累，定期除去灰尘，防止静电
- 操作后彻底清洗
- 避免与眼睛接触
- 保持容器密闭

**7.2 储存**  
- 储存于阴凉干燥处，避免阳光直射
- 25 公斤/牛皮纸袋（内衬 PP 塑料袋）
- 保质期自交货日期起为 **一年**
