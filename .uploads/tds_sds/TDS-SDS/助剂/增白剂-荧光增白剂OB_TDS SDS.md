## 第一部分：荧光增白剂 OB TDS（技术数据表）

**产品名称：** Optical Brightening Agent OB（荧光增白剂 OB）

### 化学信息

| 项目 | 内容 |
|------|------|
| 化学名称 | 2,2'-(2,5-二苯基硫代)双[5-(1,1-二甲基乙基)]苯并恶唑 |
| 分子式 | C₂₆H₂₆N₂O₂S |
| 分子量 | 430 |
| 结构式 | 苯并恶唑类衍生物 |

### 物性指标

| 项目 | 数值 |
|------|------|
| 外观 | 浅绿色粉末，无味 |
| 色光 | 蓝白光 |
| 纯度 | ≥98% |
| 熔点 | 200~202°C |
| 细度 | 超过100目 |
| 溶解性 | 溶于烷烃、脂肪、矿物油、石蜡和大多数有机溶剂 |

### 用途

- 特别适用于聚烯烃、PA（聚酰胺）、PAN（聚丙烯腈）等的增白
- 广泛用于薄膜、注塑和挤出材料
- 适用于所有塑料加工
- 也可用于涂料、印刷油墨和涂层

### 推荐用量

0.01~0.05%（基于总配方）

### 包装规格

25kg纸箱/桶，或根据用户要求定制

### 2. 危险性识别

**GHS分类：** 对水环境的慢性危害：类别4
**信号词：** 无

**危险性说明：**
- 可能会对水生生物有长期持续性危害

**其他危害：** 在一定条件下，产品可形成粉尘爆炸。

### 4. 急救措施

| 接触途径 | 措施 |
|----------|------|
| 吸入 | 如吸入粉尘后有不适感，移至空气新鲜处，就医诊治 |
| 皮肤接触 | 用肥皂和清水彻底清洗 |
| 眼睛接触 | 翻转眼睑，用流动清水清洗至少15分钟 |
| 摄食 | 清洗口腔，然后大量饮水 |

### 5. 消防措施

| 项目 | 内容 |
|------|------|
| 适宜灭火介质 | 干粉末、泡沫 |
| 禁止灭火介质 | 二氧化碳 |
| 特殊危害 | 有害蒸气，形成烟雾；遇火会释放有害物质 |
| 特殊保护设备 | 自给式呼吸器 |
| 补充说明 | 由于粉尘爆炸危险，应避免卷扬物料/产品 |

### 6. 泄漏应急处理

- 个人预防：避免形成粉尘，穿着个人防护服
- 环境保护：不得排入排水沟/地表水系/地下水系
- 清理方法：选择合适的器械处理，避免形成粉尘

### 7. 操作处置与储存

- 操作：在当地没有排气通风装置时倾倒大量产品，必须使用呼吸保护
- 防火防爆：避免形成粉尘，对静电需采取预防措施
- 储存：保持容器密封、干燥，存于阴凉处

### 8. 接触控制/个体防护

**个人防护设施：**
| 防护类型 | 要求 |
