## 一、技术数据表（TDS）

### 1.1 产品概述

HY-2801是一种改性的高分子量溶剂型环氧树脂，具有极好的柔韧性、耐化学腐蚀性、耐热性等特性。

### 1.2 主要应用

- 卷钢涂料
- 瓷釉涂料
- 可折叠管涂料
- 罐涂料
- PCM涂料

### 1.3 树脂性能

| 项目 | HY-2801 |
|------|:-------:|
| 外观 | 无明显机械杂质 |
| 环氧当量（g/eq） | 5,500~7,500 |
| 不挥发份（wt.%） | 39~41 |
| 色相（G） | 2.0 G |
| 旋转粘度（25℃） | 2,000~6,000 |

### 1.4 包装

- 180KG铁桶
- IBC吨桶

### 2.4 急救措施

| 暴露途径 | 措施 |
|---------|------|
| 眼睛接触 | 用大量水彻底冲洗至少15分钟，如有不适就医 |
| 皮肤接触 | 立即脱去污染衣物，用大量肥皂水和清水冲洗至少15分钟，如有不适就医 |
| 食入 | 切勿给失去知觉者喂食，立即呼叫医生或中毒控制中心 |
| 吸入 | 将患者移到新鲜空气处，呼吸困难给予吸氧，立即就医 |

### 2.5 消防措施

- **适当灭火介质**：适用于周围环境的灭火介质
- **特别危害**：火灾时可能产生有害可燃气体或蒸气
- **消防人员防护**：佩戴呼吸面具并穿全身防护服

### 2.6 泄漏应急处理

- 使用个人防护装备，保证充分通风
- 清除所有点火源，采取防静电措施
- 少量泄漏用干砂或惰性吸附材料吸收
- 大量泄漏需筑堤控制

### 2.7 操作处置与储存

- 在通风良好处操作，穿戴合适个人防护用具
- 远离热源、火花、明火和热表面
- 保持容器密闭，储存于干燥、阴凉和通风处
