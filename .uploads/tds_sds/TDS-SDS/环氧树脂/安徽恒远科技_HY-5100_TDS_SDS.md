## 一、技术数据表（TDS）

### 1.1 产品概述

HY-5100是一种改性的高分子量溶剂型环氧树脂，具有极好的柔韧性、耐化学腐蚀性、耐热性、优异的耐蒸煮性能。

### 1.2 主要应用

- 卷钢涂料
- 瓷釉涂料
- 可折叠管涂料
- 罐涂料
- PCM涂料

### 1.3 树脂性能

| 项目 | HY-5100 |
|------|---------|
| 外观 | 无明显机械杂质 |
| 环氧当量（g/eq） | 6,000~8,000 |
| 不挥发份（wt.%） | 39~41 |
| 色相（G） | 2.0 G |
| 旋转粘度（25℃） | 3,000~8,000 |

### 1.4 包装

- 180KG铁桶
- IBC吨桶

### 2.3 危险性概述

**GHS分类**：
- 易燃液体：类别3（H226）
- 皮肤腐蚀/刺激：类别2（H315）

**信号词**：警告

**象形图**：GHS02（火焰）、GHS07（感叹号）

**防范说明**：
- P210：远离热源/火花/明火/热表面，禁止吸烟
- P233：保持容器密闭
- P302+P352：如有皮肤沾染，使用大量水清洗
- P403+P235：存放在通风良好的地方，保持低温

### 2.4 急救措施

| 暴露途径 | 措施 |
|---------|------|
| 吸入 | 将受害人转移到空气新鲜处，必要时给予氧气或人工呼吸 |
| 皮肤接触 | 用水清洗皮肤/淋浴，立即脱掉沾染的衣服 |
| 眼睛接触 | 以水冲洗眼睛，如戴隐形眼镜取出，继续冲洗 |
| 食入 | 用水彻底漱口，勿催吐，呼叫解毒中心或医生 |
