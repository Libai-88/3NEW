# SUMILITERESIN® PR-34419 Technical Data Sheet (TDS)

> 来源：PR-34419__TDS__EN.pdf | 品牌方：sbhpp（住友电木高性能塑料事业部）

## General Description

PR-34419 is a liquid phenolic resin for can coatings, especially for BPA free coatings.（PR-34419 是一款液态酚醛树脂，专为罐头涂层设计，尤其适用于无双酚A（BPA Free）涂层。）

## Storage

This product, if stored at room temperature, will slowly change in properties. To maintain properties, the product should be kept in a cool (less than 10 deg C), dry location in closed containers.
（该产品在室温下储存时性质会缓慢变化。为保持特性，应将产品置于阴凉（10℃以下）干燥处，密闭容器保存。）
