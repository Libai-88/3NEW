# SUMILITERESIN® PR-55887 技术数据表（TDS）—— 用作涂料固化剂的液体酚醛树脂

## 主要描述

- 烷基酚改性的酚醛树脂
- 使用正丁醇作为溶剂

## 主要用途

PR-55887 是一种可用作食品包装罐内涂料硬化剂使用的液体酚醛树脂。

| 项目 | 测试条件 / 单位 | 测试值 |
|---|---|---|
| 不挥发份 | 135℃-1h, % | 49 |
| 凝胶时间 | 150℃, s | 240 |
| 粘度 | 25℃, mPa·s | 350 |

上表中的数值是具有代表性的数值。

## 储存条件

该产品在室温下，特性会发生改变。为了保持特性，建议最好将产品保存在密闭容器，置于阴凉（10℃以下）干燥且通风良好的环境内。
