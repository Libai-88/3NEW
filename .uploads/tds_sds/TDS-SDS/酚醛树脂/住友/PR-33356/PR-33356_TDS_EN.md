# SUMILITERESIN® PR-33356 Technical Data Sheet (TDS) —— Liquid Phenolic Resin

> 来源：PR-33356-EN.pdf | 修订日期：2015年7月27日 | 品牌方：sbhpp（住友电木高性能塑料事业部）

## General Description

- Modified Phenolic Resin（改性酚醛树脂）
- Solvent based liquid resin（溶剂基液态树脂）

## Application

PR-33356 is a colorant which gives clear golden color and is suitable for metal coatings.
（PR-33356 是一种可赋予清金色的着色剂，适用于金属涂料。）

## Resin Properties

| Item | Condition, Unit | PR-33356 |
|---|---|---|
| Resin Content（树脂含量） | 135°C-1h, % | 1800（原文如此） |
| Viscosity（粘度） | 25°C, mPa·s | 67 |

The values on the table are NOT specification.（表中数值不是规格值。）

## Storage

The product is a stable material with storage condition below 10°C.（该产品在10℃以下储存条件下性质稳定。）
