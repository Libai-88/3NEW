## 第一部分：技术资料（TDS）

### 产品类型与交付形式
- **类型**：可固化、未增塑酚醛树脂
- **交付形式**：72% 丁醇溶液（72B）
- **用途**：包装容器及罐体内外涂层；化工装置、容器、管道等的高附着力耐化学腐蚀防护涂层；热固化酚醛/环氧树脂组合；热固化酚醛/聚乙烯醇缩丁醛组合；耐燃油、耐油的物理干燥涂料。

### 稀释性（●=可大量/无限稀释，○=极有限或不可稀释）
- ○ 白精油；● 二甲苯；● 溶剂石脑油；● 丙酮；● 甲乙酮；● 甲基异丁基酮；● 环己酮；● 乙酸乙酯；● 乙酸丁酯；● 甲氧基丙基乙酸酯；● 甲氧基丙醇；● 乙醇；● 丁醇

### 相容性（按 PR 401/其他基料 = 90/10 至 10/90 各比例，●=确定相容）
- **酚醛树脂**：PHENODUR® PR 217、PR 285、PR 308、PR 373、PR 401、PR 404、PR 722、PR 897、PR 515——全部比例相容
- **环氧树脂**：BECKOPOX EP 301、EP 304、EP 307、EP 309——全部比例相容
- **其他基料**：Butvar B-79、B-90、B-98（聚乙烯醇缩丁醛）——全部比例相容

### 性能与用途要点
- **罐体涂层**：20–40% PR 401 + 80–60% BECKOPOX EP 307/EP 309（按固体分计）烘烤后获得高附着力、耐化学品、柔韧性好的漆膜，用于食品及奢侈品行业罐、管及其他包装容器内外涂层。
- **耐化学腐蚀防护涂层**：PR 401 可单独作高耐性烘烤瓷漆基料，漆膜较脆，仅适用于刚性基材；可用聚乙烯醇缩丁醛增塑。酚醛树脂为主的环氧组合适合耐酸环境；环氧用量大时漆膜柔韧性好、耐碱。多层涂装时首层不完全固化，与最后一层一起整体固化（如30 min / 180–210℃），用于化工容器、设备、管道耐化学内衬。

### 加工
- **树脂溶液与稀释剂制备**：酚醛树脂溶液与其他树脂溶液在室温混合；适用溶剂为乙二醇醚、酯类、双丙酮醇及高级酮类，芳烃可作稀释剂。
- **预缩合**：酚醛/环氧组合可在密闭容器、回流冷凝、持续搅拌下于110–120℃预缩合约2小时，可改善流平性和漆液稳定性。
- **烘烤条件**：视用途与膜厚，180–210℃下30–10分钟；罐涂层等薄膜10–15 min / 190–200℃即可；温度过高会损失柔韧性。
- **催化**：推荐使用酸性催化剂 ADDITOL® XK 406。

### 储存
- ≤25℃、原包装条件下储存稳定性至少 **730天**；到期后经留样QC检测可延长有效期并更新COA（仅限allnex持有物料）。

### 鉴别特征
- PR 401 漆膜几乎无色；适合与环氧搭配的等级：PR 217、PR 285、PR 401、PR 722、PR 723、PR 897。

### 2. 危险性概述
- **外观**：无色或黄色液体，醇味
- **GHS分类**：易燃液体3类；致癌物1A类；生殖细胞致突变物2类；生殖毒物1B类；特异性靶器官毒性（一次接触）3类；皮肤腐蚀/刺激2类；严重眼损伤/眼刺激1类；皮肤致敏1A类；水环境危害（急性）3类
- **警示词**：危险
- **H声明**：易燃液体和蒸气；可能致癌；怀疑造成遗传性缺陷；可能对生育能力或胎儿造成伤害；可引起昏睡或眩晕；可引起呼吸道刺激；造成皮肤刺激；造成严重眼损伤；可能导致皮肤过敏反应；对水生生物有害
- **健康危害**：急性经口（大鼠）LD50 >2000 mg/kg、经皮（兔）>2000 mg/kg、吸入（大鼠4h）LC50 >20 mg/L；过量蒸气暴露致呼吸道/眼刺激及中枢神经系统影响（头痛、头晕、恶心、共济失调、混乱、昏睡）

### 4. 急救措施
- **吸入**：转移至新鲜空气处，呼吸困难时输氧，症状持续就医。
- **皮肤接触**：立即脱去污染衣物和鞋，大量水冲洗，洗净前不再穿用；有疼感/刺激感或过暴露症状时就医。
- **眼睛接触**：大量水冲洗至少15分钟，立即就医。
- **食入**：立即打电话请医生，仅在医生指导下诱吐；勿给昏迷者经口喂食任何东西。

### 5. 消防措施
- 灭火介质：水、泡沫、二氧化碳或干粉灭火器；柱状水可能无效；避免高压水枪。暴露火中时喷水冷却容器。
- 消防员佩戴自备空气呼吸装置，穿完全防火衣。

### 6. 泄漏应急处理
- 人员防护：接触限值未知时戴正压自备空气呼吸器；穿不渗透靴。
- 环境预防：避免泄漏到环境中。
- 清除：用惰性吸收材料覆盖泄漏物→盛起放入废物回收容器→用水冲洗溢出区域→移走着火源。

### 7. 操作处置与储存
- **操作**：远离热源、火花、明火，严禁烟火；容器密闭并接地/等势连接；使用防爆电器与不产生火花的工具；防静电；戴防护手套和护眼/面罩；通风良好处操作；遵循职业接触限值。
- **储存**：凉爽、干燥、通风良好处，容器密封；配备消防器材与合规电气设备；防静电、装卸料接地；蒸汽可与空气形成爆炸性混合物；储存温度约23℃（保持品质稳定）。

### 8. 接触控制与个体防护
- **工程控制**：尽可能密闭系统加工；非密闭系统须良好覆盖和局部抽风。
- **呼吸防护**：全脸式面罩，带A型有机蒸汽过滤筒（BP>65℃）。
- **手防护**：反复/长期接触—丁腈橡胶（NBR）>0.38mm，破裂时间>480分钟；短期/防溅—NBR 0.12mm，约60分钟；天然橡胶0.12mm不适用。困难情况下使用PE手套作下层手套。
- **眼睛/身体防护**：附近设洗眼喷水器与安全淋浴器；戴防化学喷溅眼罩或面具；戴密封手套、穿防护衣；操作区不得进食饮水吸烟。
