## 2. 危险性概述

### 紧急情况概述
微黄色液体，芳香族化合物气味。**易燃液体和蒸气。** 可能引起呼吸道刺激。吞咽并进入呼吸道可能致命。**长期或重复接触会对器官造成伤害。** 可能引起昏昏欲睡或眩晕。对水生生物有毒并具有长期持续影响。

### GHS危险性类别

| 项目 | 类别 |
|------|------|
| 易燃液体 | 类别3 |
| 特异性靶器官系统毒性——单次接触 | 类别3（呼吸道刺激、麻醉作用） |
| 特异性靶器官系统毒性——反复接触 | **类别1** |
| 对水生环境的急性危害 | 类别2 |
| 慢性水生毒性 | 类别2 |

### 标签要素
- **警示词**：**危险**
- **危险性说明**：
  - H226 易燃液体和蒸气
  - 可能引起呼吸道刺激
  - 可能引起昏昏欲睡或眩晕
  - 长期或重复接触会对器官造成伤害
  - 吞咽并进入呼吸道可能致命
  - 对水生生物有毒并具有长期持续影响

## 4. 急救措施

| 途径 | 措施 |
|------|------|
| **吸入** | 务必有新鲜空气，得到医疗护理 |
| **皮肤接触** | 立即用大量水彻底清洗受污染处 |
| **眼睛接触** | 保持眼睛睁开并立即用大量水冲洗至少10分钟，立即呼叫医生 |
| **食入** | 漱口，不要催吐，立即就医治疗 |

---

## 5. 消防措施

| 项目 | 内容 |
|------|------|
| **适用的灭火剂** | 雾状水、泡沫、干粉或二氧化碳 |
| **不适用的灭火剂** | 大量水喷射 |
| **特殊危害** | 产品在火灾中产生有害烟雾，含异氰酸盐蒸气；可能产生微量其他有毒物质 |
| **防护措施** | 如发生火灾，佩戴正压自给式呼吸器 |

---

## 6. 泄漏应急处理

- **个人防护**：使用个人防护设备，保证充分通风，避免与皮肤和眼睛接触
- **环境保护**：不要排入地表水或下水道系统
- **清除方法**：用机械搬运设备，放入合适的封闭容器中待处理；适合收容的物料：砂、硅藻土、通用粘结剂

---

## 7. 操作处置与储存

- **处置**：避免皮肤和眼睛接触；利用物料转运/灌装和混合或提供局部通风；操作现场不得进食、饮水或吸烟
- **储存**：保持容器密闭；保存在良好通风处；保存在阴凉处；防止产生静电，远离火源；需要防爆装置
