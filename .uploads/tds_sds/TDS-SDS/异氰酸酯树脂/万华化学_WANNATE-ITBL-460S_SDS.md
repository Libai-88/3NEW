## 第二部分：危险性概述

### 紧急情况概述
液体，易燃。吞食后有害。对眼睛和皮肤有刺激性。跟皮肤接触可能会引起敏化。**可能会致癌。可能会引起能传代的遗传性损害。** 有毒：通过吸入、跟皮肤接触或吞食，长期接触有严重损害健康的危险。对水生物有害。

### GHS危险性类别

| 危险性类别 | 分类 |
|-----------|------|
| 易燃液体 | 类别3 |
| 急性经口毒性 | 类别4 |
| 皮肤腐蚀/刺激 | 类别2 |
| 严重眼损伤/眼刺激 | 类别2A |
| 皮肤致敏物 | 类别1 |
| 生殖细胞致突变性 | **类别1B** |
| 致癌物质 | **类别1B** |
| 特异性靶器官毒性反复接触 | 类别1 |

### 信号词
**危险**

### 危险性说明
- H226 易燃液体和蒸气
- H302 吞咽有害
- H315 造成皮肤刺激
- H317 可能造成皮肤过敏反应
- H319 造成严重眼刺激
- H340 可能造成遗传性缺陷
- H350 可能致癌
- H372 长期或反复接触会对器官造成损害

## 第六部分：泄漏应急处理

- **小量泄漏**：清除所有点火源，用吸附性物质收集，擦除残留物
- **大量泄漏**：疏散人员，穿全身防护服，防止泄漏物进入排水沟或河道，禁止吸烟和明火

---

## 第七部分：操作处置与储存

- **操作处置**：在通风良好区域使用；禁止吸烟、明火；防止产生静电；避免接触不相容物料
- **储存**：采用原装容器存放在经批准的防爆区域；存储于阴凉、干燥、通风良好的地方；禁止存放在凹坑、洼地、地下室等气体汇聚场所
