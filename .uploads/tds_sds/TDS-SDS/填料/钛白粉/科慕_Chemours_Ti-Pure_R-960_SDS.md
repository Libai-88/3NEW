## 第7部分 — 操作处置与储存

**操作处置**：
- 避免吸入粉尘
- 安全操作注意事项：这是一种完全被氧化了的矿物质产品，不会在尘埃爆炸中支持燃烧或参与燃烧

**储存**：
- 合适的储存条件：容器保持紧闭，储存在干燥通风处
- 不要让该产品在储存期间受潮

## 第11部分 — 毒理学信息

| 项目 | 结果 |
|------|------|
| **急性经口毒性（大鼠）** | LD₅₀ > 5,000 mg/kg |
| **急性经皮毒性（兔子）** | LD₅₀ > 10,000 mg/kg |
| **皮肤刺激（兔子）** | 无皮肤刺激，未被分类为刺激物 |
| **眼睛刺激（兔子）** | 未被分类为刺激物 |
| **呼吸/皮肤过敏** | 未引起试验动物过敏 |
| **生殖细胞致突变性** | 在动物细胞培养中没有引起基因损害 |

**致癌性**：
- 国际癌症研究机构（IARC）将二氧化钛列入 **2B 组（可能对人类有致癌性）**，依据是人类证据不充分、动物证据充分。
- 对欧洲和美国 20,000 多名 TiO₂ 工业工人的流行病学研究结论：不认为 TiO₂ 灰尘对人类肺部有致癌影响。
- 科慕科学家结论：在工作场所的经验浓度，二氧化钛不会引起人类肺癌或慢性呼吸疾病。

**生殖毒性**：动物试验表明无生殖毒性；无生长发育毒性。
