### 3. 危险性标识

- **危险描述**：不适用

- **附加信息**：

  - 产品具有很强吸附性，可能对皮肤和眼睛产生干燥效应

  - 超过职业接触限值时，可能对呼吸系统造成机械性过载

  - 产品粉尘颗粒的空气湍流会导致**爆炸性环境**

  - 产品**可燃** \[pdf\_21]

### 4. 急救措施

| 接触途径      | 急救措施                    |
| --------- | ----------------------- |
| **吸入后**   | 供给新鲜空气                  |
| **皮肤接触后** | 立即用水冲洗                  |
| **眼睛接触后** | 用流动水冲洗张开的眼睛数分钟；如症状持续，就医 |
| **吞咽后**   | 如出现症状，就医                |

\[pdf\_21]

### 5. 消防措施

| 项目     | 内容                |
| ------ | ----------------- |
| 合适灭火剂  | 泡沫、CO₂、沙、灭火粉末     |
| 不合适灭火剂 | 水                 |
| 特殊危害   | 发生火灾时可能释放一氧化碳（CO） |
| 防护设备   | 佩戴防护设备            |

\[pdf\_21]

### 6. 泄漏应急措施

- **人员安全预防措施**：穿戴防护服，避免产生粉尘，远离引燃源

- **环境保护措施**：不得排入下水道/地表水或地下水

- **清洁/收集方法**：清扫泄漏区域；避免扬起粉尘 \[pdf\_21]

### 7. 操作处置与储存

**操作处置**：

- 防止形成粉尘

- 作业现场需抽风

- 保持容器密封

- 使用合适的工业真空吸尘器或中央真空系统清除粉尘

- 防止静电火花

- 产品可燃，接地容器以避免电火花

**储存**：储存等级11 \[pdf\_21]

### 8. 接触控制/个人防护

**职业接触限值**：

| 组分                  | 限值                                             |
| ------------------- | ---------------------------------------------- |
| 无定形二氧化硅（7631-86-9）  | TWA（长期）：6 mg/m³（可吸入）；4.0 mg/m³（可呼吸性）           |
| 微晶石蜡和烃蜡（63231-60-7） | TWA：4.0 mg/m³（可呼吸性粉尘，8h）；10.0 mg/m³（总可吸入粉尘，8h） |

**个人防护设备**：

- **呼吸防护**：超过OES值时，使用**P2过滤口罩**

- **手部防护**：佩戴符合EN 388标准的防机械危害手套；使用稳定材料（如丁腈橡胶）手套

- **眼部防护**：安全眼镜

- **身体防护**：防护工作服 \[pdf\_21]

### 10. 稳定性和反应性

- **热分解**：按规范使用不发生分解

- **危险反应**：产品粉尘颗粒的空气湍流会导致爆炸性环境

- **危险分解产物**：CO₂、CO \[pdf\_21]

### 11. 毒理学信息

| ------- | ------- | --------------- |
| 无定形二氧化硅 | 口服 LD50 | 10000 mg/kg（大鼠） |

**其他**：

- 皮肤：无刺激效应

- 眼睛：有刺激效应

- 致敏性：无已知致敏效应

- 无定形二氧化硅在慢性口服毒性、致癌性、致畸性和生育力试验中未发现不良效应 \[pdf\_21]

### 12. 生态学信息

- 产品在化学和生物学上呈惰性

- 由于不溶于水，在任何过滤和沉淀过程中都会分离

- **鱼类毒性**：LC50（96h）>10000 mg/l（斑马鱼）

- **水蚤毒性**：EC50（24h）>1000 mg/l（大型蚤）

- 通常对水无危害 \[pdf\_21]
