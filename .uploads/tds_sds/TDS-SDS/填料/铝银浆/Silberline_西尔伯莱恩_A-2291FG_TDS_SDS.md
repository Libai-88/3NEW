## 第一部分：产品数据表（TDS）

### 1.1 产品描述

A-2291FG 是一种**超细、高遮盖力、非浮型铝颜料**，适用于溶剂型通用工业涂料。

- 非浮型
- 超细粒径，高遮盖力，添加量少
- **不适合与彩色颜料搭配使用**，不会产生干净的色彩效果 [pdf_12]

### 1.2 产品应用

- 工业涂料
- 卷材涂料
- 内罐涂料（interior can-coatings） [pdf_12]

### 1.3 技术指标

| 项目 | 指标 |
|------|------|
| 等级 | 400目等级 |
| 筛分分析 | 0.1% |
| 不挥发分 | 65%（质量比） |
| 粒径 | 8 μm（35.3% by volume） |
| 比重 | 1.47 |
| 溶剂 | 矿物油和芳香烃混合物 |

[pdf_12]

### 1.4 使用指南

1. **预浸泡**：按膏溶剂比1:1~3:1用溶剂预浸泡1~8小时。细粒径产品需要更长的浸泡时间。
2. **分散**：采用低剪切慢速混合，达到平滑均一、无结块的混合物。
3. **注意**：避免高剪切分散技术，会扭曲铝片形状。 [pdf_12]

### 1.5 储存条件

- 保存在原装运输容器中，保持密封
- 存放于干燥室温低于溶剂闪点的环境中
- 避免任何使颗粒悬浮在空气中形成粉尘云的条件
- 详情请查阅MSDS或美国铝协会TR-2手册 [pdf_12]

### 1.6 FDA合规信息

A-2291FG铝浆由**铝、斯托达德溶剂（Stoddard solvent）和芳香族溶剂**组成。

**铝作为着色剂**已在以下21 CFR条款下获得批准：

- 175.105 — 间接食品添加剂 - 粘合剂
- 175.300 — 间接食品添加剂 - 树脂和聚合物涂层
- 175.320 — 间接食品添加剂 - 聚烯烃薄膜用树脂和聚合物涂层
- 176.170 — 间接食品添加剂 - 与水性和脂肪性食品接触的纸和纸板组分
- 176.180 — 间接食品添加剂 - 与干性食品接触的纸和纸板组分
- 177.1520 — 间接食品添加剂 - 烯烃聚合物
- 177.2800 — 间接食品添加剂 - 纺织品和纺织纤维
- 178.3297 — 间接食品添加剂 - 聚合物着色剂

**斯托达德溶剂和芳香族溶剂**未通过FDA相关测试，目前未获得任何21 CFR条款的批准。使用者需自行确认产品在食品接触应用中的使用符合FDA规定。 [pdf_13]

### 2.6 泄漏应急处理

- **个人防护**：除去所有火源，让无关人员离开，使用适当防护设备
- **环境措施**：避免溢出物接触土壤、水路、排水设备和下水管道
- **清理方法**：扫净小量溢出物，避免弄出灰尘；不可使用会产生火花的工具 [pdf_14]

### 2.7 操作处置与储存

**操作**：
- 远离热、火花与火焰
- 避免着火，减少火源

**储存**：
- 将容器置于阴凉、通风处
- 使用容器前保持容器关紧与密封
- 避开一切可能引起燃烧的来源

**包装材料建议**：使用原有的容器 [pdf_14]
