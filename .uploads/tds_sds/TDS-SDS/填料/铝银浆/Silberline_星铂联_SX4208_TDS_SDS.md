## 第一部分：产品数据表（TDS / PDS）

### 1.1 产品描述

SX4208 是一种**非浮型超细粒径铝银浆**，采用**玉米片型技术**开发，具有以下特点：

- 非浮型
- 玉米片型
- 遮盖力高，添加量少
- 良好的耐化学性和分散性
- 特别适合溶剂型通用工业涂料 [pdf_6]

### 1.2 产品应用

- 工业涂料
- 卷材涂料
- 罐听涂料 [pdf_6]

### 1.3 技术指标

| 项目 | 指标 |
|------|------|
| 筛分分析（325目），质量百分比 | ≤ 0.1 |
| 固含量，质量百分比 | 64.0% |
| 平均粒径 | 8 μm |
| 水分含量，质量百分比 | ≤ 0.15% |

[pdf_6]

### 1.4 使用指南

1. **预浸泡**：使用1~3倍量的溶剂预先浸泡1~8小时。粒径小的产品需要更长的浸泡时间。
2. **分散**：采用低速低剪切力搅拌，取得无结块的均一混合物。
3. **注意**：高剪切力会破坏铝片形状，影响最终视觉效果，不推荐使用。 [pdf_6]

### 1.5 储存条件

- 保存在原装容器内，保持密封
- 存放于阴凉、干燥、通风良好、经评估合格的地点
- 避免颗粒弥漫到空气中形成粉尘云
- 避免所有可能的火源 [pdf_6]

### 1.6 FDA合规信息

SX4208 铝浆由**铝、加氢处理的轻质石油馏分和芳香族溶剂**组成。

**铝作为着色剂**已在以下21 CFR条款下获得间接食品添加剂使用批准：

- 175.105 — 粘合剂
- 175.300 — 树脂和聚合物涂层
- 175.320 — 聚烯烃薄膜用树脂和聚合物涂层
- 176.170 — 与水性和脂肪性食品接触的纸和纸板组分
- 176.180 — 与干性食品接触的纸和纸板组分
- 177.1520 — 烯烃聚合物
- 177.2800 — 纺织品和纺织纤维
- 178.3297 — 聚合物着色剂

**加氢处理的轻质石油馏分和芳香族溶剂**尚未按照FDA法规完成测试，目前未获得21 CFR任何条款的批准。用户需自行确认产品用于特定食品接触应用前符合FDA相关规定。 [pdf_1]

**补充声明**（2023-11-24，星铂联雅思达颜料质检部）：SX-4208所用原材料全部符合**FDA 21 CFR 175.300**认可、**国标GB9685-2016**以及**欧洲EC No.1935/2004**，可在食品接触等级系列产品中使用。 [img_4]

### 2.4 急救措施

| 接触途径 | 急救措施 |
|----------|---------|
| **眼睛接触** | 立即用大量水冲洗，不时提起上下眼睑，连续冲洗至少10分钟；如疼痛就医 |
| **吸入** | 将患者转移到空气新鲜处，保持呼吸畅通；如无呼吸，由受过训练的人员进行人工呼吸或给氧 |
| **皮肤接触** | 用大量水冲洗受污染皮肤，脱去污染衣物和鞋子 |
| **食入** | 用水冲洗口腔；禁止催吐；如患者清醒可饮少量水；切勿给失去意识者任何口服物 |

### 2.6 泄漏应急处理

- **个人防护**：疏散周围区域，切断所有点火源，提供足够通风，穿戴适当个人防护装备
- **环境措施**：避免溢出物进入土壤、河流、下水道
- **清理方法**：使用防火花工具和防爆装置，扫净溢出物，装在适当容器中处理 [pdf_5]

### 2.7 操作处置与储存

**操作**：
- 穿戴适当个人防护设备
- 禁止食入，避免接触眼睛、皮肤及衣物
- 仅在充足通风条件下使用
- 远离热源、火花、明火

**储存**：
- 储存于原装容器中，防止直接光照
- 置于干燥、凉爽、通风良好的区域
- 远离禁忌物（酸、氧化物质、强碱、卤代烃）
- 已开封容器须小心再封好并保持直立 [pdf_5]
