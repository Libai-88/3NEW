# 技术数据表（TDS）

## PHENODUR® PR 516/60B

**品牌：** allnex（湛新树脂）
**类型：** 可固化、未增塑酚醛树脂
**交货形式：** 60% 溶于丁醇（60B）

---

## 用途

与环氧树脂组合使用，具有优异的附着力、硬度和柔韧性。对化学品、矿物油和食品具有非常好的耐受性。基于Phenodur PR 516的涂料优选用于金属包装物品的内部涂装。

---

## 性质与用途

Phenodur PR 516尤适用于与高分子量环氧树脂组合，如Beckopox EP 304、EP 307和EP 309。此类组合适用于配制透明、热固化涂料，用于金属包装物品（如可折叠管、罐、以及水、油和食品容器）的内部涂装。此类涂料可耐受多种酸、碱、有机溶剂和食品。

---

## 加工

Phenodur PR 516与高分子量环氧树脂的组合需在190-210°C下烘烤10-20分钟以达到完全固化。可使用酸性催化剂如Additol XK 406（用量为固体树脂的2-5%），可将温度降低至180-200°C，并可能改善附着力和硬度。

在多涂层体系中，首层涂层无需完全固化，整个涂层体系仅在最后一层涂装后方完全固化。如出现表面缺陷（催化体系更易出现），加入约1-3%的三聚氰胺树脂（如Maprenal MF 800）可作为优异的流平剂。酚醛树脂与环氧树脂在约100°C（回流）下的预缩合也可改善成品涂料的流平性。

Phenodur PR 516与环氧树脂的混合比应为1:2至1:4（以固体树脂计）。

---

## 稀释性与相容性

Phenodur PR 516可无限稀释于醇类、酯类和酮类。可有限稀释于芳烃和脂肪烃。PR 516与高分子量环氧树脂和聚乙烯醇缩丁醛相容。

---

## 显著特点

Phenodur PR 516比Phenodur PR 217、PR 722、PR 723和PR 897反应性更高、颜色更浅。Phenodur PR 516与Phenodur PR 515相当，但不含双酚A作为单体。

---

## 储存

在高达25°C的温度下，原始包装中的储存稳定性至少为365天。
