## 1. 产品描述

Tyzor® GBA 和 Tyzor® GBO 是特种钛螯合物等级产品。含有混合醇，即使在低温储存条件下也能保持液态。Tyzor GBA 和 GBO 为黄色至红色有机液体。

---

## 2. 功能特性

| 功能 | 说明 |
|------|------|
| **附着力促进** | 改善基材附着性能 |
| **交联** | 与多种功能性聚合物进行交联 |
| **涂层形成** | 形成聚合物二氧化钛层，作为粘合剂或涂层 |
| **路易斯酸催化** | 在酯化、酯交换、缩合、加成等反应中作为催化剂 |

## 4. 应用领域

### 印刷油墨
- 在溶剂型印刷油墨（如基于硝化纤维素的油墨）中作为优良的交联剂和附着力促进剂
- 改善干燥速度、耐溶剂性、耐热性和对基材的附着力

### 涂料
- 作为涂料添加剂，交联含 -OH 和 -COOH 官能团的聚合物或粘合剂
- 促进附着力，或本身作为粘合剂使用

### 颜料/填料处理
- 玻璃、金属、填料和颜料经处理后，可提高表面硬度、附着力、耐刮擦性、着色效果、耐热和光反射性、彩虹色效果和耐腐蚀性

### 催化应用
- 催化酯化和酯交换反应，用于各种酯类和聚酯
- 催化聚氨酯的缩聚和加成反应
- 优势：无副产物、高产率、操作简单、催化剂浓度低

## 5. 使用方法

| 应用方式 | 说明 |
|----------|------|
| **作为添加剂** | 通常作为最后一种成分加入，以防止与水或其他配方成分发生不必要的预反应。交联反应中通常添加到聚合物或粘合剂中。 |
| **作为底漆** | 以极低浓度溶解于有机溶剂中，涂覆于基材表面。 |
| **溶胶-凝胶体系** | 全部或部分水解 Tyzor 钛乙酰丙酮化物（通常与其他金属醇盐配合），制得金属氧化物，用作粘合剂或涂层。 |
