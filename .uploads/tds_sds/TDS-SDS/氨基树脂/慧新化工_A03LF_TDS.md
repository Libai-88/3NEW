## 二、产品规格

| 项目 | 指标 |
|------|------|
| 色数（Fe-Co比色计） | ≤ 1 |
| 固含量（%） | 60 ± 2 |
| 粘度（mPa·s，25℃） | 500 – 1500 |
| 酸价（mg KOH/g，固体） | ≤ 1.0 |
| 游离甲醛（%） | ≤ 2.5 |
| 溶剂 | 异丁醇 / 二甲苯 |

---

## 三、应用特性

1. 高硬度，高光泽，附着力佳
2. 游离甲醛含量低
3. 低臭味佳，极佳的储存稳定性

---

## 四、应用范围

1. 一般金属涂装烤漆
2. 自行车、家电等金属烤漆
